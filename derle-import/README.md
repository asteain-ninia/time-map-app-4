# derle-import — デーレ界の実データ置き場

デーレ界の地図データ（`.gimoza`）と、その元になった SVG を置いてある。

**生成する道具はここには無い**。SVG から `.gimoza` を作る処理は 2026-08-16 に
`../derle-map-visualizer` へ一本化した（同じ処理を 2 つ持つ意味が無いため）。
このディレクトリに残っているのは**データと、出来上がった `.gimoza` を調べる補助**だけ。

**元データ**: `イラレ出界図BUR080809.svg`（ユーザーが 2026-08-09 に .ai から書き出したもの。
`derle-map-visualizer` 同梱の 1/13 版ではない）。国名ラベルは 89 → 126 件に増えており、
不明国の括弧付きラベルなども入っている。

## ファイル

| ファイル | 内容 | git 追跡 |
| --- | --- | --- |
| `イラレ出界図BUR080809.svg` | 元データ | する |
| `derle-world-full.gimoza` | フル解像度。**正準データ** | しない |
| `derle-world.gimoza` | 間引き版。ベンチ・軽量編集用 | しない |
| `derle-world-full-2026-08-16.gimoza` / `derle-world-2026-08-16.gimoza` | 新しいパイプラインで作り直したもの。**上の 2 つは上書きしていない**（アプリで編集している可能性があるため）。中身を確かめて問題なければ差し替える | しない |
| `world-rect.json` | SVG 内の世界矩形（座標変換の値。現在は visualizer が SVG から直読するため参照用） | する |
| `borders.json` / `borders-states.json` | 旧パイプラインの中間データ（2026-08-09 の抽出結果。再生成には不要） | しない |
| `basemap-vector.json` / `basemap.png` | 背景地図の資産（`.gimoza` に同梱されるので単体では不要） | しない |
| `crop-*.png` / `preview*.png` ほか | 目視確認のために焼いた画像 | しない |

`.gimoza` を追跡しないのは、**アプリで編集する実データでもある**ため。編集のたびに
ツリーが汚れる。中間データも合計 19 MB あり、再生成できるものを毎回積むのは割に合わない。

## 作り直しかた

`../derle-map-visualizer/index.html` をブラウザで開き、

1. `イラレ出界図BUR080809.svg` を読み込む
2. 「州境界で階層化する」にチェック（デーレ共和国・正統ノル王国・ラヴィエンド・ウィル同君王国を
   集約地物にするため。外すとフラットな出力になる）
3. フル版なら「目標頂点数」を空欄に、間引き版なら数値を入れる（従来は 16500）
4. 「.gimoza を書き出し」

出来たファイルをこのディレクトリに置く。処理の中身と、その設計理由は
`../derle-map-visualizer` の要件定義書 §6.10〜§7 と AGENT.md にある。

同じ手順をヘッドレスで自動実行することもできる（変換ロジックは持たず、上のブラウザ操作を
そのまま踏むだけ。実装は visualizer 側の 1 つのまま）:

```
node derle-import/tools/rebuild.mjs                         # フル版
node derle-import/tools/rebuild.mjs --target-vertices=16500 # 間引き版
```

## 検証

整合性チェック（両 `.gimoza` とも `ok=true` / 不整合 0 であること）:

```
npx vite-node derle-import/tools/diagnose-consistency.ts derle-world-full.gimoza
```

実データベンチ:

```
DERLE_TMAP_DIR=e:/WORKSPACE/time-map-app-4/derle-import npx vitest run src/ui/map/derle-benchmark.test.ts
```

階層が正しく組めているかは次で確認する（フル版と間引き版で集約 3・子の数が一致すること）:

```
node derle-import/tools/inspect-hierarchy.mjs derle-import/derle-world-full.gimoza derle-import/derle-world.gimoza
```

`tools/` に残してあるのは、`rebuild.mjs` 以外はいずれも**出来上がった `.gimoza` を調べる**ためのもの:

- `inspect-hierarchy.mjs` — 集約地物と子の数を一覧する
- `diagnose-consistency.ts` — 整合性チェックを掛けて不整合を一覧する
- `diagnose-pair.ts` — 2 つの地物のどこが重なっているかを見る
- `diagnose-perf-depth.ts` / `diagnose-selection.ts` — 描画・選択の性能を測る
- `dump-agg-shape.ts` — 集約地物の派生形状を吐く
- `preview-tmap.mjs` — `.gimoza` を重ね描きした PNG を出す

## データについての申し送り

ここに書いてあるのは**このデータ固有の事実**で、道具の話ではない。

- **バアカが海域を持たないのは正しい**（ユーザー裁定 2026-08-09・調査不要）。当初「コルニア近辺・
  バアカ・コルニア東の不明国は海上国境を持つはず」との報告を受けたが、欠けていたのは
  コルニアと東コルニア不明国だけで、こちらは修正済み（橋渡しで海域が閉じた）。バアカは元地図にも
  西側・北側の海の国境線が無く（`crop-borders-only.png` で確認）、**南極圏に近い国で南限と
  コルニアとの境界だけが定まっている**ため、海岸線どまりの領域として抽出されるのが作図意図どおり。
  **直そうとしないこと** — 橋渡しの半径を上げて無理に閉じると、意図的に開いている海の国境まで
  誤って繋いでしまう。
- **階層**（ユーザー裁定 2026-08-09）:
    - **デーレ共和国** = 集約。子は州名付きの州 + 領海 + 無名領域
    - **正統ノル王国** = 集約。州境界線はあるが州名は無いので、地名ラベルから命名
      （ウサイモ島・ペレッサ・ガーミアッサ・南ケナ地方・グシアッサ・エッサ大平野）
    - **ラヴィエンド・ウィル同君王国** = 集約。**一国で正解だが 1 個下の層で分かれる**のが要件。
      同君連合として 2 国を 1 つの集約にまとめている
- **洋上ラベル 5 件の手動割当**（ユーザー裁定 2026-08-08）: ピニア・テレン合議国・バアカ・
  ヤシュー・アレファクト・ニィル。ポリゴンの id は抽出のたびに変わるので、内部点の座標で指定している
- **命名の衝突 1 件**: 「ジアーラ・ジアーラ内不明国」— 同一ポリゴンに両方のラベルが載る。
  未割当のラベル 2 件:「（東ウィータ不明国）」「マカ」（どのポリゴンにも入らない）。
  いずれもアプリ内で改名・再割当できる
- **測地系**: 赤道長 42,035 km（derle-climate の惑星半径 1.0489 地球半径 × 40,075 km）、
  扁平率 0（未設定のため球面近似）
- 東西の地図端で分断された大陸は、端で別の地物のまま（アプリ内で合体できる）
