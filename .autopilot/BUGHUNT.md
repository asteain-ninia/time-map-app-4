# バグハント・フェーズ — 未知の人間クラスバグを能動的に炙り出す

人間バグ修正(HUMAN-BUGS.md)の後、安定ウィンドウの前に実行。既知バグの回帰テスト(守り)とは別に、**まだ誰も気づいていない未知バグを自動で発見**するための攻めの工程。Codex 全面投入・デグレ厳禁・発見バグは各々に回帰E2Eを添える。

## 手法（全部入れる）

1. **UIファズ/モンキー + 不変条件**: Playwright で擬似ランダムな実操作列(seedは args/固定で決定論)を多数流す。各ステップ後に常時不変条件をアサート: クラッシュ無し / console error・warning・unhandled rejection ゼロ / カメラ transform に NaN/Infinity 無し / リング幾何が常に妥当(交互/包含/非交差) / 選択が常に有効 / undo スタック整合。
2. **メタモルフィック/オラクル**: 期待値を人が書かず関係で判定。保存→読込=恒等(round-trip) / 追加→undo=無操作 / パン+Δ→−Δ=元 / ズームin→out=元 / 時間 t→t'→t=元 / 分割→undo=元。fast-check + Playwright で生成。
3. **ビジュアル回帰**: 主要画面 + ランダム操作後の画面を `toHaveScreenshot` で基準比較(オフスクリーン決定論描画でベースライン安定)。空サイドバー/無スタイル/欠落の見た目崩れを画像検出。
4. **AI探索テスター**: エージェントが Playwright 探索スクリプトを書き、実アプリをユーザー的に操作(メニュー/モード切替/追加/編集/分割/時間移動/保存読込/undo/パン/ズーム)→各ステップのスクショ + console + 状態ダンプ(JSON)を artifacts に保存→実行→**Claude が PNG を Read で画像判定 + Codex が同 artifacts/コードを局所精査**し「おかしい所」を候補バグとして列挙→三角測量→実在のみ修正+回帰E2E。
5. **厳格エラーゲート**: 全 E2E で console error/React warning/unhandled rejection/NaN を即失敗に格上げ(現状の console-clean を全シナリオへ拡張)。

## 出力
- 観測フック(camera pan/zoom・mode・selection・sidebar 中身)を data-testid/E2E_TEST で拡充(behavioral-e2e-standard)。
- 発見した未知バグ: Codexレビュー込みで根本修正、バグごと commit、各々に回帰E2E。
- ファズ/オラクル/ビジュアル/エラーゲートを恒久スイート化(CI で未知バグの再侵入を防ぐ)。
- 限界の明記: 主観UX品質("惜しい"レベル)は人間レビューに残す。明白な機能/視覚/状態バグは自動で刈る。

## 不変条件
- 非対話・GUI起動なし・タイムアウト前提。デグレ厳禁(毎回フルスイート緑)。commit はローカルのみ。
