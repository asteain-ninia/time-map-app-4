# U29 末端→集約遷移と直轄領自動生成

## 目的

末端地物が所属変更フロー（U28）の中で「下位領域を獲得する」結果状態に至ったとき、その時刻から当該地物を集約地物へ遷移させる純粋ロジックを提供する。本ユニットは、遷移に伴う以下の不可分な変換を `domain` 層の純粋関数として組み立てることを目的とする。

- 元末端地物の同一性を保ったまま、その時刻から集約地物として継続させる（新規地物として作り直さない）。
- 元末端地物のプロパティ（名称・種別ラベル・属性）を新集約地物へ引き継ぎ、形状属性は破棄する（集約地物は形状属性を保持せず、形状は下位領域の和として実行時算出される）。
- 元末端地物の形状と、新たに得た下位領域の和との差分を評価し、差分が空でなければ差分領域を「直轄領」末端地物として自動生成し、新集約地物の下位領域に追加する（差分が空なら生成しない）。
- 差分が地理的に分離している場合、1 つの直轄領末端地物を複数の領土リング（飛び地）で表現する。
- 集約地物が全下位領域を失った結果状態になったら、その時刻以降に自動消滅させる。

本ユニットは「集約地物は直接追加できず、下位領域の追加と所属変更を組み合わせて構成する」という階層モデルの不変条件（FR-35）を、遷移ロジックの構造として体現する。遷移・直轄領生成・自動消滅はいずれも単一の不可分な変換として組み立て、所属変更フロー（U28）の 1 アンドゥ単位の一部として確定される。

## スコープ

### やること

1. **末端→集約遷移（FR-36）**
   - 所属変更フロー（U28）の確定結果として「ある末端地物が、その時刻に 1 つ以上の下位領域を持つ結果状態になる」場合、その時刻からその地物を集約地物へ遷移させる純粋変換を提供する。
   - 遷移判定は、特定の操作種別（割譲・連邦化・直轄化など）や呼び出しフラグでゲートせず、変異後の結果状態（下位領域を 1 つ以上持つか）で行う（教訓 5.6）。下位領域を獲得させる経路が複数あっても、すべて同じ結果状態判定を通る。
   - 遷移は地物の同一性を保ったまま、その時刻の状態スナップショット（歴史の錨）として記録する。元末端地物を削除して別 ID の集約地物を新設するのではなく、同一識別子の地物が「その時刻から集約地物として継続する」状態を構成する。
   - 遷移時刻より前の錨は変更しない（過去の末端地物としての状態は保持される）。遷移は当該時刻以降の状態にのみ作用する（FR-55 の伝播遮断と整合）。

2. **元プロパティの引き継ぎと形状属性の破棄（FR-36）**
   - 元末端地物のプロパティ（名称・種別ラベル・属性、および色情報等の属性一式）を、新集約地物の同時刻の状態へ引き継ぐ。
   - 元末端地物が保持していた形状属性（外周・穴・飛び地のリング構造）は、集約地物の状態からは破棄する。集約地物は形状属性を保持せず、形状は全直接下位領域の和として実行時に算出される（FR-35）。
   - 引き継ぐ属性と破棄する形状の区別は、判別共用体（末端地物／集約地物）に沿って型レベルで表現し、集約地物に形状属性が残る不正状態を表現不能にする。

3. **直轄領の差分算出と自動生成（FR-37）**
   - 「元末端地物の形状」と「新たに集約地物の下位領域となった全領域の和」の差分（元形状 − 下位領域の和）を、U06 のブーリアン演算（差・和）で算出する。
   - 差分が空（許容トレランス内で面積ゼロ）なら直轄領を生成しない。差分が空でなければ、差分領域を担う直轄領末端地物を 1 つ自動生成し、新集約地物の下位領域に追加する。
   - 自動生成される直轄領は末端地物であり、形状を保持する。直轄領を追加した結果、集約地物の形状（＝全直接下位領域の和）が元末端地物の形状に厳密一致し、集約地物内部に隙間が生じないこと（FR-39）を保つ。
   - 差分算出の入力（下位領域の和）は、遷移により下位領域となった全領域を対象とする。複数の下位領域が獲得される場合は全片の和をとり、片落とし（先頭片だけ採用）をしない（教訓 5.1）。

4. **地理的分離時の複数領土リング表現（FR-37）**
   - 差分（元形状 − 下位領域の和）が地理的に複数の分離片に割れる場合、それらを別々の地物に分割するのではなく、1 つの直轄領末端地物を複数の領土リング（飛び地）で表現する。
   - 差分が穴・ネスト構造を含む場合も、U06 が返す多重ポリゴン構造（外周＋穴リング・複数外周＝飛び地）をそのまま直轄領末端地物の形状として保持する。リング階層は常に領土→穴交互の不変条件（FR-24）を満たす。

5. **直轄領の既定名称とダイアログ上書き（FR-37）**
   - 直轄領末端地物の既定名称を「`<元名> 直轄領`」とする（`<元名>` は元末端地物＝新集約地物の名称）。
   - 所属変更フロー（U28）のダイアログから、ユーザーが直轄領の名称を上書きできる入口を提供する。上書きがなければ既定名称を用いる。
   - 既定名称の組み立ては単一の生成規約として 1 箇所に定義し、複数経路で別実装にしない（単一の真実源）。名称文字列の表示・編集 UI は U28 側のダイアログが担い、本ユニットは既定名称の算出と、上書き値があればそれを採る合成ロジックを提供する。

6. **集約地物の全下位領域喪失による自動消滅（FR-35 / FR-41）**
   - ある時刻に集約地物が全下位領域を失った結果状態になったら、その時刻以降、当該集約地物を自動的に非存在（消滅）とする。
   - 消滅判定は、削除経路・所属変更経路・解体経路など特定の入力経路でゲートせず、変異後の結果状態（その時刻に直接下位領域が 0 個か）で行う（教訓 5.6）。同じ「全下位領域喪失」を複数経路が引き起こすため、経路ごとのゲートは別経路で漏れる。
   - 自動消滅は当該時刻以降に作用し、その時刻より前に集約地物が下位領域を持っていた状態は保持される（時間的飛び地＝非存在期間として表現する。FR-56）。

7. **集約地物を直接追加させない構造保証（FR-35）**
   - 本ユニットは「集約地物を直接新設する」公開経路を持たない。集約地物は、末端地物が下位領域を獲得する遷移（本ユニット）か、結合（合体）の結果としてのみ生じ得る（合体は別ユニットの責務）。
   - 集約地物の構成は必ず「下位領域の追加＋所属変更」を経由する。本ユニットの変換 API は、入力として「下位領域を獲得する末端地物」と「獲得される下位領域集合」を受け取り、結果として遷移後の地物状態を返す形に限定する。集約地物を空（下位領域 0 個）で生成する入口は設けない。

8. **変換結果の不可分性と再解決情報の返却**
   - 遷移・直轄領生成・自動消滅を 1 つの不可分な変換として組み立て、所属変更フロー（U28）が単一アンドゥ単位として確定できる編集案（または編集案断片）を返す（FR-94）。
   - 変換結果は、テストで厳密比較できる構造化結果として、(a) 集約地物へ遷移した地物の識別子、(b) 自動生成した直轄領末端地物の識別子（生成した場合のみ）、(c) 自動消滅させた集約地物の識別子（あれば）を列挙して返す。U28・選択再解決（教訓 5.11）・整合性維持（U13）がこの結果から後続処理を組み立てられるようにする。

### やらないこと

- **所属変更フローそのもの**（割譲・連邦化・独立・帰属・直轄化・自治化・解体の UI フロー、新親候補の循環参照チェック、新規上位領域作成サブフロー）は U28 の責務。本ユニットは U28 が「下位領域を獲得させる」結果を渡してきたときの遷移変換と、その副産物（直轄領生成・自動消滅）のみを担う。所属変更の事前条件検証（循環参照防止など）を本ユニットで実装しない（教訓 5.27）。
- **集約地物形状＝直接下位領域の和の検証**は U08 の責務。本ユニットは「直轄領を足すと和＝元形状になる」関係を生成する側であり、その結果が不変条件（FR-35 / FR-39）を満たすかの検証は U08 の検証関数を確定前に呼び出して担保する（生成と検証を分離する）。
- **ブーリアン演算（差・和・交差）そのものの実装**は U06 の責務。差分算出・和集合算出は U06 のラッパ経由で行い、`polygon-clipping` を直接 import しない。座標量子化・トレランス・退化ケース防御は U06 に委譲する。
- **末端地物同士の空間的排他検証・エッジ滑り・近接スナップ・共有頂点化**は別ユニットの責務。自動生成した直轄領末端地物が他の末端地物と重ならないかの最終検証は、確定時に整合性維持プロセス（U13）へ委ねる。本ユニットは直轄領の形状を「元形状 − 下位領域の和」として算出するのみで、排他衝突の解決は行わない。
- **合体（結合）による集約地物生成**（FR-50 / FR-51 の末端＋集約混在パターン等）は別ユニットの責務。本ユニットの遷移は「所属変更で下位領域を獲得する」経路に限定する。ただし「集約地物を直接追加しない」原則（FR-35）は両者で共有する不変条件であり、互いに矛盾しないよう整合させる。
- **時間軸・歴史の錨列の再編**（錨の追加・分割・短縮・削除、昇順・非重複維持）の汎用処理は時間モデルユニットの責務。本ユニットは「遷移時刻以降に作用し、過去の錨を変更しない」「自動消滅は当該時刻以降に作用する」という時間境界の規約を満たす形で錨を構成するが、錨列再編アルゴリズム自体は委譲する。
- **描画・ヒットテスト・ラベル配置・表示フォーカス**（集約地物の派生形状描画など）は描画／表示ユニットの責務。本ユニットは状態を構成するのみで表示制御を持たない。
- **ダイアログの描画**（直轄領名称入力欄を含む所属変更ダイアログの UI）は U28／UI 層の責務。本ユニットは既定名称の算出と上書き値の合成という純粋ロジックのみを提供する。

## 依存(dependsOn)

依存ユニットの公開インタフェース（関数名・引数・戻り値型）は偶然の文字列一致に頼らず、共有型・両側テストで固定する（教訓 5.33）。依存ユニットが未実装の場合は、本仕様に記す入出力契約に沿った型インタフェースを先に定義し、その型に対して遷移ロジックと単体テストを実装する。

- **U28 — 所属変更フロー（FR-46〜FR-48）**: ツリー位相を変える単一フロー。本ユニットは U28 が確定しようとしている結果状態のうち「ある末端地物が下位領域を獲得する」ケースで起動される。U28 から本ユニットへの入力契約は概ね次の形とする。
  - 入力: `(現在状態, 下位領域を獲得する末端地物の識別子, 獲得される下位領域の識別子集合, 遷移時刻, 直轄領名称の上書き値（任意）)`。
  - 出力: 遷移後の状態（または U28 が組み立てる編集案へ統合できる断片）と、上記「変換結果の構造化情報」（遷移地物 ID・生成した直轄領 ID・消滅させた集約地物 ID）。
  - 本ユニットは U28 の循環参照チェック・親候補絞り込み・ダイアログ駆動を担わない。直轄領名称の上書き値は U28 のダイアログが収集して本ユニットへ渡す。
- **U06 — 幾何述語・座標量子化・ブーリアン演算ラッパ**: 直轄領の差分算出（元形状 − 下位領域の和）と下位領域の和集合算出に、U06 の差（difference）・和（union）演算を用いる。U06 は結果を多重ポリゴン型（複数ポリゴン・外周＋穴リング）で返し、複数片を保全し（教訓 5.1）、演算前量子化・演算後の不変条件再検証を内部で行う（技術方針 R2）。差分が空か（面積ゼロか）の判定は U06 のトレランス基準に整合させ、本ユニットで独自のトレランスを再定義しない（単一の真実源）。`polygon-clipping` を本ユニットから直接呼ばない。
- **U08 — ツリー階層モデルと不変条件検証**: 末端／集約の判別（下位領域を持つかの結果状態判定）、最上位フラグと親なしの同値、集約地物形状＝直接下位領域の和の検証、循環に耐える親子走査を提供する。本ユニットは、(a) 遷移判定の「下位領域を持つか」の結果状態判定を U08 と同一の判別ロジックで行い、(b) 遷移・直轄領生成・自動消滅の結果が U08 の検証関数で違反なしと判定されることを確定前に確認する（生成は本ユニット、検証は U08。教訓 5.26）。末端／集約の判別を本ユニットで別実装しない（単一の真実源）。

> dependsOn に挙がっていない要件（描画・排他検証・タイムライン UI）には依存しない。本ユニットの入力は「遷移対象の末端地物・獲得される下位領域・遷移時刻・名称上書き値」というプレーンなデータであり、出力は遷移後の状態スナップショットと構造化結果である。

## 実装方針(技術方針に沿う)

- **配置層と純粋性**: 本ユニットの中核（遷移変換・直轄領差分算出・既定名称合成・自動消滅判定）は、すべて `domain` 層の副作用のない純粋関数として実装し、Electron／React／Canvas に一切依存せず Vitest 単体で実行できる状態を保つ（技術方針 2.13 / NFR 5.8）。入力状態を破壊的に変更せず、Immer による不変更新で新状態を返す（技術方針 2.6）。ダイアログ描画・名称入力 UI は本ユニットに含めない（U28／UI 層）。
- **不正状態の型排除（技術方針 2.1 / 4.43）**: 「集約地物は形状属性を保持しない」「最上位フラグと親なしの同値」を U03 系の判別共用体で型表現する。遷移後の集約地物に形状属性が残る状態、下位領域 0 個の集約地物が存続する状態を、可能な限り型レベルで表現不能にし、型で表しきれない実行時不変条件（形状＝和・隙間なし）は U08 の検証で確定前に担保する。
- **結果状態での判定（教訓 5.6 / 開発ガイド §4）**: 末端→集約の遷移トリガーと、集約地物の自動消滅トリガーは、いずれも「特定の入力経路（操作種別・呼び出しフラグ）」でゲートせず、変異後の結果状態（その時刻に下位領域を 1 つ以上持つか／0 個か）で判定する。同じ結果状態を生む経路を列挙し（割譲・直轄化・自治化・解体・合体など）、経路ごとのゲートが別経路で漏れないことを回帰テストで網羅する。
- **集合演算の全片保全（教訓 5.1）**: 下位領域の和・差分は複数ポリゴン・複数リングを返す前提で扱う。差分が複数片に割れる場合（地理的分離）は、全片を 1 つの直轄領末端地物の複数領土リングとして取り込み、先頭片だけ採用しない。下位領域が複数獲得される場合の和も全片を対象にする。
- **派生形状の単一解決判定（教訓 5.29）**: 集約地物の形状＝下位領域の和という派生形状の解決判定は U08（と共有する形状解決規約）に集約し、本ユニットは「直轄領を足すと和＝元形状になる」関係を生成する側として同一の解決判定に乗せる。本ユニットが独自の形状算出を別実装してドリフトさせない。
- **単一の真実源（開発ガイド §4）**: (a) 末端／集約の判別、(b) 量子化トレランス、(c) 直轄領の既定名称生成規約、(d) 差分が空かの面積ゼロ判定、はそれぞれ単一実装として 1 箇所に定義し共有する。
- **不可分性とアンドゥ単位（FR-94 / 技術方針 2.6）**: 遷移・直轄領生成・自動消滅は、所属変更フロー（U28）の単一アンドゥ単位の一部として 1 つの不可分な変換にまとめる。部分確定（遷移だけ確定して直轄領未生成、など）を許可しない。再 do 時に直轄領末端地物の ID を採番し直さず初回生成 ID を復元できるよう、生成 ID は復元可能な形で結果に含める（教訓 5.20 / 5.37、ID 生成は ID 生成サービス経由で重複検査する）。
- **確定前検証（教訓 5.26）**: 遷移・直轄領生成・自動消滅で構成した結果状態は、確定前に U08 の階層不変条件検証（形状＝和・隙間なし・最上位フラグ同値・循環なし）と、整合性維持プロセス（U13）の空間競合検証（自動生成直轄領が他の末端地物と重ならないか）に通す。本ユニット単体では幾何排他の最終解決を行わないが、検証で違反が出た場合はテスト可能な戻り値（拒否理由）で報告できる構造にする。
- **構造変更後の選択再解決（教訓 5.11）**: 遷移・自動生成・消滅で対象 ID・形状が変わるため、変換結果に「遷移地物 ID・新規直轄領 ID・消滅地物 ID」を含め、U28／選択ユニットが完了後の選択を結果から再解決できるようにする。固定の全クリアで決めない。
- **トレランスと退化ケース（技術方針 R2）**: 差分算出は U06 のラッパ経由で量子化・不変条件再検証を通す。差分が空かの判定はトレランス内の面積ゼロ判定で行い、polygon-clipping 由来の微小スリバーを「直轄領あり」と誤検出しない。逆に正当な細い直轄領をトレランスで消失させないよう、U06 と同一のトレランス基準に整合させる。
- **世界端ラップとの整合（技術方針 R3）**: 元形状や下位領域が世界端（経度 ±180 度境界）をまたぐ場合、差分・和は U05／U06 のラップ展開済み座標上で行う。直轄領が世界端をまたぐ飛び地になるケースでも分断・片落としを起こさないことを確認する。

## 受け入れ基準(テスト可能な形で列挙)

各基準は Vitest 単体テストまたは fast-check プロパティテストで、`domain` 層の純粋関数として検証できる形で満たすこと。

1. **末端→集約遷移と元プロパティ引き継ぎ・形状属性破棄（FR-36）**
   - ある末端地物が遷移時刻に 1 つ以上の下位領域を獲得する入力で、その時刻からその地物が集約地物として継続する状態が構成される（遷移時刻以降の状態が集約地物になる）。
   - 遷移後の集約地物が、元末端地物の名称・種別ラベル・属性（色情報を含む）を引き継いでいる。
   - 遷移後の集約地物が形状属性を保持しない（集約地物の状態に外周・穴・飛び地のリング構造が残らない）。
   - 遷移は地物の同一性を保つ（元末端地物と同一識別子で集約地物として継続し、別 ID へ作り直されない）。
   - 遷移時刻より前の錨（末端地物としての過去状態）が変更されない。

2. **複数経路から同一の遷移結果（教訓 5.6）**
   - 「末端地物が下位領域を獲得する」という同一の結果状態を生む複数の入力（例: 既存地物を子に移す割譲型・新規上位を挟む自治化型・直轄化型など、U28 由来の異なる操作種別）に対し、いずれも同じ遷移結果（集約化・引き継ぎ・形状破棄）が得られる。
   - 遷移トリガーが特定の操作種別フラグでなく結果状態（下位領域 1 個以上）で判定されることを、フラグ非依存の入力で確認する。

3. **差分から直轄領を自動生成・差分空なら生成しない（FR-37）**
   - 元形状が下位領域の和より広い（差分が空でない）入力で、差分領域を持つ直轄領末端地物が 1 つ自動生成され、新集約地物の下位領域に追加される。
   - 自動生成された直轄領を含む全下位領域の和が、元末端地物の形状に厳密一致する（U08 の形状＝和検証で違反なし・集約地物内部に隙間なし）。
   - 元形状と下位領域の和が一致する（差分が空＝面積ゼロ）入力で、直轄領を生成しない（下位領域は獲得分のみ）。
   - 差分が極小スリバー（トレランス内で面積ゼロ）の入力で、直轄領を生成しない（微小スリバーを直轄領化しない）。

4. **地理的分離時の複数領土リング表現（FR-37）**
   - 差分が地理的に複数の分離片に割れる入力で、それらが別々の地物ではなく 1 つの直轄領末端地物の複数領土リング（飛び地）として表現される。
   - 差分が穴・ネスト構造を含む入力で、直轄領末端地物が U06 の多重ポリゴン構造をそのまま保持し、リング階層が領土→穴交互の不変条件（FR-24）を満たす。
   - 差分の全片が直轄領に反映される（片落としがない。教訓 5.1）。

5. **直轄領の既定名称とダイアログ上書き（FR-37）**
   - 名称上書き値が与えられない場合、直轄領の名称が「`<元名> 直轄領`」（`<元名>` は元末端地物＝新集約地物の名称）になる。
   - 名称上書き値が与えられた場合、直轄領の名称がその上書き値になる。
   - 既定名称の生成規約が単一実装で、元名称を変えると既定名称も連動することを確認する（規約の単一の真実源）。

6. **集約地物の全下位領域喪失による自動消滅（FR-35 / FR-41）**
   - ある時刻に集約地物の直接下位領域が 0 個になる結果状態の入力で、その時刻以降、当該集約地物が自動的に非存在（消滅）になる。
   - 消滅が当該時刻以降にのみ作用し、その時刻より前に下位領域を持っていた状態が保持される（時間的飛び地として表現される）。
   - 「全下位領域喪失」を生む複数経路（下位領域の削除・所属変更で全下位を別親へ移す・解体）に対し、いずれも結果状態判定で自動消滅が発火する（経路ごとのゲート漏れがない。教訓 5.6）。
   - 下位領域が 1 個でも残る場合は消滅しないことを確認する（過剰消滅の防止）。

7. **集約地物を直接追加させない（FR-35）**
   - 本ユニットに集約地物を空（下位領域 0 個）で新設する公開経路が存在しないことを、API 形状（入力に「獲得される下位領域集合」が必須で空集合を受理しない、または空集合では遷移を行わない）で確認する。
   - 集約地物が生じるのは末端地物の下位領域獲得遷移によってのみであることを、本ユニットの公開 API の入出力で固定する。

8. **不可分性と構造化結果（FR-94 / 教訓 5.11 / 5.20）**
   - 遷移・直轄領生成・自動消滅が 1 つの変換結果として返り、部分確定（遷移のみで直轄領未生成など）が生じない。
   - 変換結果に、遷移地物 ID・自動生成した直轄領 ID（生成時のみ）・自動消滅させた集約地物 ID（あれば）が列挙され、後続の選択再解決・整合性検証がこの結果から組み立てられる。
   - 再 do 時に直轄領末端地物の ID が初回生成 ID と一致する（採番し直さない。教訓 5.20）。

9. **確定前の不変条件検証（教訓 5.26 / U08 連携）**
   - 遷移・直轄領生成・自動消滅で構成した結果状態を U08 の検証へ通すと、形状＝和・隙間なし・最上位フラグ同値・循環なしが違反なしになる正常ケースを確認する。
   - 直轄領生成後の集約地物形状が元形状からはみ出す／隙間を残すような不正な構成を作ろうとした場合、確定前検証が違反を検出してテスト可能な戻り値で拒否できる。

10. **世界端ラップ・純粋性・非機能（技術方針 R3 / NFR 5.8）**
    - 元形状・下位領域が世界端（経度 ±180 度境界）をまたぐ入力で、差分・和が分断・片落としを起こさず、世界端をまたぐ直轄領飛び地が正しく構成される。
    - 本ユニットの全関数が副作用を持たず、同一入力に対し同一結果を返す（純粋性）。入力状態を破壊的に変更しない。
    - 種別ラベルを変えても遷移・直轄領生成・消滅の構造結果が変化しない（種別ラベルは表示専用で整合性に非関与。FR-40）ことを確認する。

## 関連要件(FR-id)

- **FR-35**: 集約地物は形状属性を保持せず、形状は全直接下位領域の和集合として実行時に算出される。集約地物は直接追加できず、下位領域の追加と所属変更を組み合わせて構成する。集約地物が全下位領域を失うとその時刻以降自動的に消滅する。（本ユニットは遷移・直接追加禁止・自動消滅を担当。形状＝和の検証自体は U08。）
- **FR-36**: 末端地物が所属変更フローで下位領域を獲得すると、その時刻から集約地物へ遷移する。元のプロパティ（名称・種別ラベル・属性）は新集約地物へ引き継ぎ、形状属性は破棄する。
- **FR-37**: 末端地物→集約地物の遷移時、元形状と新下位領域の和に差分があれば、差分領域を「直轄領」末端地物として自動生成し新集約地物の下位領域に追加する（差分が空なら生成しない）。差分が地理的に分離する場合は 1 つの末端地物を複数領土リングで表現する。直轄領の既定名称は「`<元名> 直轄領`」でダイアログで上書き可能。

関連する横断要件: FR-39（集約地物形状は全直接下位領域の和に厳密一致し内部に隙間を作らない・確定前に U08 で検証）、FR-41（集約地物が下位領域を全て失った場合の自動消滅）、FR-24（リング階層の領土→穴交互不変条件・直轄領が複数リング/穴を持つ場合）、FR-55/FR-56（遷移・消滅が当該時刻以降に作用し過去の錨を変えない・非存在期間の表現）、FR-94（複合操作の不可分性）、NFR 5.8（不変条件の機械的検証・純粋ロジックの分離）、技術方針 R2（退化ケース防御）、R3（世界端ラップ整合）。

## 注意点・既知の落とし穴(開発ガイドの教訓を踏まえる)

着手前に、以下の関連教訓を節番号・見出し・本文ごと引用し、今回の実装判断へどう適用するかを「適用:」として明示してから着手すること（開発ガイド §1.6 AI 作業開始ゲート）。

- **教訓 5.6（状態変化の検出は結果状態で判定する）** — 適用: 末端→集約の遷移トリガーと集約地物の自動消滅トリガーを、特定の入力経路（操作種別・呼び出しフラグ・引数の有無）でゲートせず、変異後の結果状態（その時刻に下位領域を 1 個以上持つか／0 個か）で判定する。同じ結果状態を生む経路（割譲・直轄化・自治化・解体・合体・下位領域削除）を列挙し、経路ごとに回帰テストを置いて網羅漏れを防ぐ。本ユニットの中核不変条件であり、FR-35 の自動消滅は「結果状態で判定」が要件本文に明記されている。
- **教訓 5.1（集合演算は複数片を返す前提で扱う）** — 適用: 差分（元形状 − 下位領域の和）と下位領域の和を多重ポリゴン前提で扱い、差分が複数片に割れる地理的分離ケースで全片を 1 つの直轄領の複数領土リングとして取り込む。先頭片のみ採用する処理を作らない。差分が 2 片以上になる入力で全片が直轄領に現れることをテストする。
- **教訓 5.25（仕様が限定した対象範囲を実装で広げない）** — 適用: 「集約地物は直接追加できない」「集約地物は形状属性を保持しない」「自動消滅は全下位領域喪失時」という仕様の限定を、対称性・自然な拡張を理由に広げない。例えば「下位領域 0 個でも集約地物として存続できる入口」を利便性で足さない。広げたくなったら FR-35 の本文を引用してから判断する。
- **教訓 5.26（編集制約はコマンド確定前にも同じサービスで検証する）** — 適用: 遷移・直轄領生成・自動消滅で構成した結果状態を、UI 候補表示だけでなく確定前にも U08 の階層不変条件検証と U13 の空間競合検証へ同一サービスとして通す。拒否理由はユーザー通知（日本語文言は呼び出し側）とテスト可能な戻り値の両方で扱える構造化結果にする。
- **教訓 5.27（結合と所属変更は事前条件を分けて検証する）** — 適用: 本ユニットの遷移は「所属変更で下位領域を獲得する」経路に限定し、結合（合体）による集約地物生成と混同しない。所属変更固有の事前条件（循環参照防止）は U28 の責務として分離し、本ユニットでは結果状態の構成と直轄領生成のみを担う。
- **教訓 5.11（構造変更操作後の選択は結果から再解決する）** — 適用: 遷移・直轄領自動生成・自動消滅で対象 ID・形状が変わるため、変換結果に「遷移地物 ID・新規直轄領 ID・消滅地物 ID」を含め、U28／選択ユニットが完了後の選択を結果から再解決できるようにする。固定の全クリアで決めない。
- **教訓 5.20（元に戻す情報は依存データも含めて過不足なく保存する）／5.37（ID 生成はタイムスタンプ単独に依存しない）** — 適用: 自動生成する直轄領末端地物の ID は ID 生成サービス経由で採番し既存との重複を検査する。re do 時に採番し直さず初回生成 ID を復元できるよう、生成 ID を結果に含めて履歴へプレーン形式で保存する。
- **教訓 5.21（削除は参照掃除と連鎖剪定まで行う）** — 適用: 集約地物の自動消滅は単に当該時刻以降を非存在にするだけでなく、残存要素の状態からその集約地物への参照（上位/下位参照）を同じ操作内で掃除し、参照が消えて空になった派生要素の連鎖消滅を考慮する。片方向・単一時点だけの掃除は dangling 参照を残す。ただし参照掃除・連鎖剪定の汎用処理が削除ユニット側にある場合は重複実装せず、その共有サービスを呼ぶ（過少共有の戒め／単一の真実源）。
- **教訓 5.29（派生形状は単一の解決判定で全経路を動かす）** — 適用: 集約地物の形状＝下位領域の和という派生形状の解決判定は U08 と共有する単一の解決判定に乗せ、本ユニットが「直轄領を足すと和＝元形状になる」関係を独自の形状算出で別実装してドリフトさせない。
- **教訓 5.30（過少共有と過剰共有の両方を戒める）** — 適用: 末端／集約の判別・量子化トレランス・既定名称生成・面積ゼロ判定は単一実装を共有する（過少共有の戒め）。一方で、本ユニットの遷移生成ロジックを、制約規則の異なる結合（合体）の集約生成や U28 の親候補絞り込みと安易に共有しない（過剰共有の戒め）。共有前に「2 操作の制約は本当に同一か」を列挙確認する。
- **トレランスと数値誤差（技術方針 R2）** — 注意: 差分が空かの判定を厳密等価でなく U06 と同一のトレランス内面積ゼロ判定で行う。トレランスが粗すぎると正当な細い直轄領が消失し、細かすぎると微小スリバーを直轄領化する。U06 のトレランス定数に整合させ、本ユニットで独自に再定義しない。
- **無主地の許容（FR-39）** — 注意: 直轄領は「集約地物配下を下位領域の和で完全被覆する（隙間なし）」ために生成するものであり、地図全体としてどの末端地物にも覆われない無主地は許容される。本ユニットは集約地物内部の被覆完全性のみを対象とし、森全体の被覆完全性を生成・検証対象にしない（過剰生成・過剰検証の防止）。
- **遷移時刻境界と過去錨の不変（FR-55 / FR-56）** — 注意: 遷移・直轄領生成・自動消滅はいずれも遷移時刻以降にのみ作用させ、過去の錨（末端地物としての過去状態・集約地物が下位を持っていた過去状態）を書き換えない。当該時刻以降のみへの作用と、非存在期間（時間的飛び地）の構成を境界条件としてテストで固定する（紀元前・錨境界・非存在期間を網羅。NFR 5.8）。
- **集約地物に形状属性を残さない（FR-35）** — 注意: 遷移時に元末端地物の形状属性を破棄し、集約地物の状態に外周・穴・飛び地のリング構造を残さない。判別共用体で集約地物に形状属性が乗らないよう型表現し、属性引き継ぎ（名称・種別・属性）と形状破棄を取り違えないことをテストで固定する。
