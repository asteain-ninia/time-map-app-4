# U27 穴あけによる新地物生成

## 目的

末端地物の内部に、ユーザーが指定した領域を **新しい独立した末端地物** として生成し、同時に元の末端地物にはその指定領域に対応する **穴** を形成する操作（穴あけによる新地物生成）を、ドメイン層の純粋なコマンドとして実装する。新規に生成される末端地物の上位領域は、元末端地物の上位領域を初期継承する（FR-45）。

本ユニットの核心は、**「穴/飛び地追加（単一面情報の形状編集）」と「穴あけによる新地物生成」が別概念であり、別経路として実装される** ことを構造的に保証することにある。前者（FR-22 / FR-23）はくり抜くだけで地物数を増やさない単一面情報の形状編集であり、後者（本ユニット・FR-45）はくり抜いた領域を新しい末端地物として生み出し、地物数を 1 つ増やす操作である。要件は前者について「新しい独立した面情報を生成しない（くり抜いて新地物を作る場合は穴あけによる新地物生成機能を使う）」と明示的に対象範囲を限定している（FR-23）。この限定を実装で取り違えると、形状編集が新地物を生んだり、穴あけが地物を増やさなかったりする対概念矛盾が生じる。

本ユニットは、この操作を **複合操作（穴の形成＋新地物の生成＋上位領域の継承＋整合性維持）を不可分の 1 アンドゥ単位** として確定するコマンドとして提供する。幾何ブーリアン演算は U06、リング階層の整合は U07（U06 経由で利用可能）、確定時の整合性維持プロセスは U13 へ委譲し、本ユニットはこれらを束ねる業務ロジックに徹する。

## スコープ

### やること

- **穴あけ新地物生成コマンドの実装**（FR-45）。入力として「対象となる元末端地物」「くり抜く指定領域（リングを成す閉じた頂点列）」「編集基準時刻（現在選択時刻）」を受け取り、次の結果を不可分の 1 操作として生成する純粋コマンドを提供する。
  1. **元末端地物への穴形成**: 元末端地物の形状から指定領域を差し引き（U06 の差演算）、差し引いた指定領域を元末端地物の穴リングとして表現した新形状を、元末端地物の当該時刻の錨へ反映する。元末端地物は同一性を保ったまま形状変化として続く。
  2. **新独立末端地物の生成**: 指定領域そのものを形状（領土リング）とする新しい末端地物を生成する。新地物は元末端地物とは別の同一性（新規 ID）を持つ独立した末端地物となる。
  3. **上位領域の初期継承**: 新地物の上位領域（親領域）を、編集基準時刻における元末端地物の上位領域に初期設定する（FR-45）。元末端地物が最上位（親なし）であれば新地物も最上位として生成する。
- **指定領域の妥当性検証**。くり抜く指定領域が、穴あけ操作として成立する条件を満たすことを確定前に検証する。
  - 指定領域は最低 3 頂点で有効なリングを成すこと。
  - 指定領域が元末端地物の内部に完全包含され、元末端地物の外周境界と交差しないこと（穴として成立する条件。U06 の幾何述語・U07 のリング整合で検証）。
  - 穴形成後の元末端地物・新地物の双方が、最低 3 頂点で有効なポリゴンを成すこと。
- **編集基準時刻の取り扱い**。穴あけは元末端地物の当該時刻の状態に対して行う。過去編集の規約（FR-57）に従い、同時刻の錨があればそれを更新し、なければ編集時刻を開始時刻とする新しい錨を当該時刻で有効な錨を引き継いで追加する。元末端地物の未来側の錨は自動変更しない。
- **複合操作の単一アンドゥ単位での確定**（FR-94）。穴形成・新地物生成・上位領域継承・整合性維持プロセスの結果全体を、U13 経由で 1 回のアンドゥで完全復元できる不可分の 1 コマンドとして確定する。
- **確定時の整合性維持プロセスのトリガー**（FR-61〜FR-63）。穴あけ確定時に U13 の整合性維持プロセスを起動する。穴あけは原理上、新地物が元末端地物の穴に収まるため新たな末端重なりを生まないことが期待されるが、整合性維持プロセス自体は固定順序で必ず通す（候補表示に依存せず確定前に再検証する。教訓 5.26）。
- **前後状態を一意に決める純粋関数としての結果**。コマンドは「現在ドメイン状態 ＋ 穴あけ入力」を受け取り、「次ドメイン状態（穴を持つ元末端地物 ＋ 新独立末端地物）」または「拒否（理由つき）」を判別共用体で返す。前後状態テストで「新地物と穴の対応」を検証できる戻り値とする。

### やらないこと

- **穴/飛び地追加（単一面情報の形状編集。FR-22 / FR-23）の実装**。穴をくり抜くだけで新地物を生まない形状編集は別ユニット（U25）の責務であり、本ユニットでは実装しない。本ユニットは両者を **別経路（別コマンド）** として明確に分離する側に立つ。本ユニットのコマンドは必ず新地物を 1 つ生成し、地物数を増やす。地物数を増やさない経路を本ユニットに同居させない。
- **ブーリアン差演算そのものの実装**（U06 の責務）。面の差・交差・量子化・退化ケース防御・複数片保全は U06 のラッパへ委譲し、本ユニットでは `polygon-clipping` を直接 import しない。
- **リング階層の交互不変条件検証・包含検証・削除再編アルゴリズムの実装**（U07 の責務）。穴形成後のリング階層が「領土→穴→領土→…」の交互を保つか、指定領域が外周に完全包含されるか等の検証は U07（および U07 が利用する U06 述語）へ委譲する。
- **整合性維持プロセスの骨格（固定順序オーケストレーション・競合検出・差分調整・競合解決ダイアログ駆動データ）の実装**（U13 の責務）。本ユニットは穴あけの編集案を組み立てて U13 へ渡し、結果を受け取って分岐するだけである。
- **競合解決モーダル・指定領域の作図 UI・プレビュー描画・地図上のクリック入力収集**（UI／描画層の責務）。本ユニットは UI が組み立てた「指定領域（頂点列）」と「対象末端地物」を入力として受け取る純粋ロジックであり、地図上での領域指定操作の実装は行わない。
- **アンドゥ・リドゥの二重スタック実装・コマンド適用機構**（履歴ユニットの責務。U13 経由で利用）。本ユニットは「この複合変更を 1 アンドゥ単位として確定してほしい」と依頼する立場。
- **分裂（ナイフツール。FR-44）・所属変更（FR-46）・合体（FR-50）の実装**。これらはツリー位相を変える別の操作であり別ユニットの責務。本ユニットは穴あけによる新地物生成（FR-45）のみを扱う。
- **集約地物への穴あけ**。穴あけの対象は末端地物に限る。集約地物は形状属性を持たず形状は下位領域の和として算出されるため（FR-35）、直接の穴あけ対象にしない。集約地物が対象として渡された場合は拒否する。

## 依存（dependsOn）

本ユニットは以下を呼び出す。いずれも `domain` 層の純粋関数・純粋サービス／コマンドとして提供される前提で、本ユニットはそれらのインタフェース契約に依存する。依存ユニットの公開インタフェース（関数名・引数・戻り値型）は偶然の一致に頼らず、共有型を import し両側テストで固定する（教訓 5.33 / 5.34）。依存ユニットが未実装の場合は、本仕様に記す入出力契約に沿った型インタフェースを先に定義し、その型に対して本ユニットのコマンドと単体テストを実装する。

- **U25（穴/飛び地追加＝単一面情報の形状編集）**: 本ユニットの **対概念** にあたるユニット。U25 は「くり抜くが新地物を生まない」形状編集（FR-22 / FR-23）を担う。本ユニットは U25 を直接呼び出すわけではないが、U25 と **同一の入力（対象末端地物・指定領域）から別経路で分岐する** 関係にあるため、両ユニットが混同されない契約を共有する。具体的には、両者が共有しうる「指定領域の作図結果」「内部判定（最初のクリックが面の内部か外部か等、U25 側の自動判定）」を再利用する場合でも、本ユニットの確定経路（新地物生成）と U25 の確定経路（形状編集のみ）が型レベルで分かれていることをテストで固定する（教訓 5.30 過剰共有の戒め／教訓 2.10 対概念整合）。U25 が未実装でも、本ユニットは自前の指定領域妥当性検証と新地物生成コマンドを完結して実装できる。
- **U13（整合性維持プロセスの骨格）**: 穴あけの編集案（元末端地物の穴付き新形状＋新独立末端地物の生成＋上位領域継承）を 1 つの不可分な複合変更として渡し、固定順序の整合性維持プロセス（時間整合性検証→空間競合検出→競合解決→単一アンドゥ単位での一括確定）を通して確定する（FR-61〜FR-63 / FR-94）。本ユニットは整合性維持の順序・競合検出・差分調整・履歴積みを自前で実装せず、U13 へ委譲する。
- **U06（幾何述語・座標量子化・ブーリアン演算ラッパ）**: 元末端地物の形状から指定領域を差し引く差演算、指定領域が元末端地物の内部に完全包含され外周と交差しないことの幾何述語（点in多角形・線分交差・包含・自己交差）、座標量子化と退化ケース防御を利用する。ブーリアン演算は複数片を返しうる前提で全片を扱う（教訓 5.1）。`polygon-clipping` を本ユニットから直接呼ばず、必ず U06 のラッパ経由で利用する。

本ユニットは `domain` 層の純粋関数／純粋コマンドとして実装し、Electron／React／Canvas に一切依存しない。Vitest 単体で実行可能であること。

## 実装方針（技術方針に沿う）

- **配置層**: `domain` 層（フレームワーク非依存・純粋）に置く。Electron／React／Canvas に依存させず、Vitest 単独で実行できること。穴あけコマンドは副作用のない純粋関数として書き、整合性維持の重い計算（U13 経由）が計測で 100ms を超えると判明した場合に限り後から Web Worker へオフロードできるよう、外部 I/O・グローバル状態への依存を持たせない（技術方針 R9）。
- **純粋関数・イミュータブル更新**: 入力ドメイン状態を破壊的に変更しない（教訓 5.22 確定まで共有データを破壊更新しない）。コマンドは「現在状態 ＋ 穴あけ入力」を入力に取り、「次状態」または「拒否（理由つき）」を判別共用体で返す。イミュータブル更新は Immer の構造共有を用い、アンドゥスタックのメモリ効率を保つ（技術方針 2.6）。不正状態（穴を持たない元末端＋新地物なし、新地物が末端でない等）を型で表現不能にする（技術方針 2.1）。
- **ブーリアン演算の委譲と複数片保全（教訓 5.1）**: 元末端地物の穴形成は U06 の差演算で行う。差演算は複数片を返しうる（指定領域が元末端を分断する位置にある等）。返却された全片を扱い、片落とし（先頭片のみ採用）をしない。本ユニットでは差演算結果を「元末端地物の領土リング＋指定領域に対応する穴リング」を含む多重ポリゴンとして保持する。穴あけ後の元末端の形状が複数の領土リング（飛び地）に分かれる場合も、全片を保持する。
- **指定領域の妥当性検証（確定前・教訓 5.26）**: 指定領域が穴として成立する条件（最低 3 頂点・元末端の内部に完全包含・外周と非交差・自己交差なし）を、UI の候補表示に依存せず本ユニットのコマンド確定前にも U06／U07 の同じ検証サービスで検証する。違反時は確定せず、機械可読な拒否種別と日本語のユーザー向けメッセージ（FR-115）の両方を持つ拒否を返す。
- **対概念の分離（教訓 2.10 / 5.25 / 5.30）**: 本ユニットのコマンドは必ず新地物を 1 つ生成し地物数を増やす。地物数を増やさない形状編集（U25）と同居させない。両経路が同じ入力（対象末端地物・指定領域）を共有しうるとしても、確定処理は型レベルで分岐させ、本ユニットの確定が「穴形成＋新地物生成」を、U25 の確定が「形状編集のみ」を行うことをそれぞれのテストで固定する。「対称性確保」「自然な拡張」を理由に対象範囲を広げない（教訓 5.25）。
- **上位領域の初期継承（FR-45）**: 新地物の親領域は、編集基準時刻における元末端地物の親領域から導出する。元末端が最上位なら新地物も最上位フラグを真にする。「最上位フラグが真」と「親領域が無い」は同値という不変条件（FR-39）を、新地物の生成時にも満たす。継承した親が集約地物である場合、その集約地物の形状＝下位領域の和（FR-35）の不変条件は、新地物が元末端の穴に収まることで（元末端＋新地物の和＝元末端の元形状）維持されることを前提とするが、この階層整合の最終検証は U13 の整合性維持プロセスに委ねる。
- **編集基準時刻と過去編集規約（FR-57）**: 穴あけは編集基準時刻（現在選択時刻）における元末端地物の状態に対して行う。同時刻の錨があれば更新、なければ当該時刻で有効な錨を引き継いで新しい錨を当該時刻に追加する。元末端の未来側の錨は自動変更しない（FR-55）。新地物の最初の錨の開始時刻は編集基準時刻とし、これが新地物の存在開始となる（FR-54）。
- **完全状態の一体編集（FR-59）**: 属性のみでなく、穴あけは元末端の形状・新地物の形状・親子関係・存在状態を一体の編集案として扱い、部分確定を許可しない。編集案は不変の値オブジェクトとして U13 へ渡す。
- **単一アンドゥ単位（FR-94 / 教訓 5.20 / 5.23）**: 穴形成・新地物生成・上位領域継承・（あれば整合性維持の差分調整）を、U13 を通じて不可分の 1 コマンドとして記録する。途中で別アンドゥ単位に割れないことを保証する。新地物に採番した ID は、redo で採番し直さず初回生成 ID を復元する（教訓 5.20）。U13 経由のコマンドは execute／undo／redo が touch した全地物（元末端・新地物・継承親）へ対称に通知される前提とする（教訓 5.23）。
- **構造変更後の選択再解決（教訓 5.11）**: 穴あけは新地物 ID を生み、元末端の形状を変える。コマンド結果は「形状変化して残る元末端地物 ID」「新規生成された新地物 ID」を返し、UI 層が結果から選択を再解決できるようにする（本ユニットは戻り値でこれらを返すだけで、UI 側の選択更新は行わない）。
- **無限横スクロール対応（技術方針 R3）**: 元末端地物・指定領域は世界端をまたぐ場合がある。座標の周期境界ラップ正規化は U06／U05 側で処理される前提とし、本ユニットは経度を連続スカラーのまま受け渡して独自にラップ処理を行わない。
- **エラー処理（FR-115 / FR-117）**: すべての拒否理由・例外は捕捉し、日本語のユーザー向けメッセージへ写像する。依存ユニットからの想定外戻り値など重大な内部不整合は「開発者へ報告してください」案内付きのメッセージとして扱う。

### 成果物・公開インタフェース（型レベルの契約）

実装者は以下の概念を型として定義すること（名称は実装で確定してよいが、契約の意味は固定）。

- 穴あけ入力（DrillInput 相当）: 対象元末端地物 ID・くり抜く指定領域（閉じた頂点列／リング）・編集基準時刻・（任意）新地物の名称や種別ラベルの初期値を持つ不変値。集約地物を対象に渡せない（型または検証で弾く）。
- 穴あけ結果（判別共用体）:
  - `成功`: 次ドメイン状態・形状変化して残る元末端地物 ID・新規生成された新地物 ID・新地物が初期継承した上位領域 ID（最上位なら親なしを示す値）。新地物と穴の対応（新地物の領土リング座標＝元末端に空いた穴リング座標）を前後状態テストで検証できる情報を含む。
  - `拒否`: 拒否種別（対象が集約地物／指定領域が内部に包含されない／指定領域が無効（3 頂点未満・自己交差）／穴あけ後に有効ポリゴンを成さない／整合性維持で拒否 等）と、日本語のユーザー向けメッセージ、機械可読な詳細。

公開する主関数（概念）:
- 穴あけ実行: `(現在状態, 穴あけ入力) → 穴あけ結果`。指定領域の妥当性検証 → U06 差演算による穴形成 → 新独立末端地物の生成 → 上位領域の初期継承 → U13 整合性維持プロセスによる単一アンドゥ単位での確定、までを固定順序で行う。途中で拒否が出たら後続へ進まず即座に拒否を返す（早期リターン）。

## 受け入れ基準（テスト可能な形で列挙）

以下はすべて `domain` 層の純粋関数として Vitest で「入力状態 → コマンド呼び出し → 期待結果状態」を検証できる形で満たすこと。受け入れ基準の 1・5 は前後状態テストで「新地物と穴の対応」を検証する中核基準である。

1. **末端内部の指定領域が新独立末端地物として生成され元末端に穴が形成される（FR-45）**
   - 単一の領土リングからなる末端地物の内部に指定領域を与えて穴あけを実行すると、結果状態に「指定領域に対応する穴リングを持つ元末端地物（同一 ID 保持）」と「指定領域を領土リングとする新しい末端地物（新規 ID）」の両方が存在することを検証する。
   - 元末端地物の同一性が保たれ（ID 不変・形状変化として継続）、新地物が独立した別の同一性（別 ID・末端地物）であることを検証する。
   - 穴あけ後の地物数が、穴あけ前より **ちょうど 1 つ増える** ことを検証する（形状編集と異なり新地物を生む）。

2. **新規地物の上位領域が元末端の上位領域を初期継承する（FR-45）**
   - 元末端地物が集約地物 A を上位領域に持つ状態で穴あけすると、新地物の上位領域が A になることを検証する。
   - 元末端地物が最上位（親なし）の状態で穴あけすると、新地物も最上位（親なし・最上位フラグ真）として生成されること、「最上位フラグ真＝親なし」の同値（FR-39）を満たすことを検証する。

3. **穴/飛び地追加（形状編集）と穴あけ（新地物生成）が別経路で混同しない（FR-23 / 教訓 5.25 / 5.30）**
   - 同じ入力（対象末端地物・指定領域）に対して、本ユニットの穴あけコマンドは地物数を 1 増やすこと、対概念である形状編集（U25、または本仕様で定義する形状編集の契約スタブ）は地物数を増やさないことを、それぞれ別の確定経路として検証する。
   - 本ユニットのコマンドが「形状編集のみ（新地物なし）」で終わる経路を持たないこと（必ず新地物を生成すること）を型／テストで固定する。

4. **確定時に整合性維持プロセスがトリガーされ、複合操作が単一アンドゥ単位になる（FR-61 / FR-94）**
   - 穴あけ確定時に U13 の整合性維持プロセス（固定順序）が呼ばれることを、依存をスパイ／スタブ化したテストで検証する。
   - 穴形成・新地物生成・上位領域継承・整合性維持の結果全体が、U13 を通じて 1 つの不可分コマンド（1 回のアンドゥで全復元、コマンドが 2 個以上に割れない）として記録されることを検証する。
   - アンドゥで穴あけ前の状態（穴のない元末端・新地物なし・地物数が元どおり）へ完全復元され、リドゥで新地物の ID が初回生成 ID のまま復元される（採番し直さない）ことを検証する（教訓 5.20）。

5. **前後状態テストで新地物と穴の対応が検証される**
   - 穴あけ後、新地物の領土リング（外周）座標と、元末端地物に空いた穴リングの座標が、量子化トレランスの範囲で一致（対応）することを前後状態の比較で検証する。
   - 元末端地物の元形状 ＝ 穴あけ後の元末端地物（穴を含む実効領域）＋ 新地物の形状、が和として一致すること（くり抜いた分が過不足なく新地物になっていること）を U06 の和演算で検証する。

6. **指定領域の妥当性検証と拒否（教訓 5.26 / FR-115）**
   - 指定領域が 3 頂点未満・自己交差を含む場合に確定せず拒否を返すことを検証する。
   - 指定領域が元末端地物の内部に完全包含されず、外周境界と交差する／外部にはみ出す場合に拒否を返すことを検証する。
   - 拒否結果が「機械可読な拒否種別」と「日本語のユーザー向けメッセージ」の両方を持つことを検証する。

7. **対象は末端地物に限る（FR-35 / 教訓 5.25）**
   - 集約地物を対象に渡した場合、確定せず拒否（対象が集約地物）を返すことを検証する。穴あけの対象範囲を末端地物以外へ広げないことを固定する。

8. **複数片を返す差演算で全片が保持される（教訓 5.1）**
   - 指定領域が元末端地物を複数領域へ分断するような位置にある入力で、穴あけ後の元末端地物が複数の領土リング（飛び地）を含む形でも、全片が結果に保持され片落としが起きないことを検証する（差演算の複数片結果を全片反映）。

9. **編集基準時刻と過去編集規約（FR-57 / FR-55）**
   - 編集基準時刻に同時刻の錨がある場合はその錨が更新され、ない場合は当該時刻で有効な錨を引き継いだ新しい錨が追加されることを検証する。
   - 元末端地物の未来側の錨が自動変更されないこと、新地物の最初の錨の開始時刻が編集基準時刻になることを検証する。

10. **`domain` 純粋性**: 本ユニットの全関数が副作用を持たず、Electron／React／Canvas に依存せず Vitest 単体で実行できることを確認する。

## 関連要件（FR-id）

- **FR-45（must・本ユニットの主担当）**: 穴あけによる新地物生成として、末端地物内部に指定した領域を新しい独立した末端地物として生成し、元の末端地物には対応する穴を形成する。新規地物の上位領域は元末端地物の上位領域を初期継承する。
- **FR-23（must・対概念）**: 穴/飛び地の追加は単一面情報の形状編集であり、新しい独立した面情報を生成しない（くり抜いて新地物を作る場合は穴あけによる新地物生成機能を使う）。本ユニットは FR-23 が指す「新地物を作る場合」の機能を担い、形状編集（FR-22 / FR-23）とは別経路であることを保証する。
- **FR-61〜FR-63（must）**: 確定時に固定順序の整合性維持プロセスを実行し、空間競合があれば競合解決を経て、適用後は単一アンドゥ単位とする。本ユニットは穴あけ確定時にこのプロセス（U13）をトリガーする。
- **FR-94（must）**: 分割・結合・所属変更などの複合操作は不可分の 1 操作として履歴記録・整合性検証を一括完了し、1 回のアンドゥで復元できる。穴あけも複合操作としてこの不可分性を満たす。

併せて満たす土台となる横断要件: FR-26 / FR-27（末端地物同士のみの排他）、FR-35（集約地物は形状を持たない＝穴あけ対象外）、FR-39（最上位フラグと親なしの同値）、FR-54 / FR-55 / FR-57 / FR-59（歴史の錨・過去編集・完全状態の一体編集）、FR-115 / FR-117（日本語エラーメッセージ）。技術方針 R2（退化ケース防御＝U06）・R3（無限横スクロール）。

## 注意点・既知の落とし穴（開発ガイドの教訓を踏まえる）

着手前に、以下の関連教訓を節番号・見出し・本文ごと直接引用し、今回の実装判断へどう適用するかを「適用:」として明示してから実装すること（開発ガイド §1.6 AI 作業開始ゲート）。

- **教訓 2.10 対概念へ判断を反映する**: 「ある概念に仕様判断を加えたら、その対概念にも同じ判断を反映する（混在結合↔既存への子追加、リーフ↔コンテナ、同一性継続↔同一性終了 等）。検索だけでなく、対概念の説明文がその判断と整合するかを能動的に確認する。」
  - 適用: 本ユニット（穴あけ＝新地物生成）と U25（穴/飛び地追加＝形状編集）は対概念である。本ユニットに「新地物を必ず生む」判断を入れる以上、対概念である形状編集が「新地物を生まない」ことと整合しているかを能動的に確認し、両者の確定経路が型レベルで分かれていることをテストで固定する。受け入れ基準 3 で固定する。

- **教訓 5.25 仕様が限定した対象範囲を実装で広げない**: 「ドメインの基本ルール（排他性・整合性・階層）が仕様で対象を明示的に限定しているとき、実装で『対称性確保』『自然な拡張』を理由に対象範囲を広げない。直感的拡張と感じた変更ほど、仕様で例外規定されている可能性を疑い、変更前に仕様の該当節を引用する。」
  - 適用: 穴あけの対象は末端地物に限る（FR-35 で集約地物は形状を持たないため対象外）。また FR-23 が形状編集の対象範囲を「新地物を生まない」と限定している。これらを「対称性」「自然な拡張」を理由に広げない。集約地物への穴あけ拒否（受け入れ基準 7）と、形状編集との非混同（受け入れ基準 3）で固定する。

- **教訓 5.30 過少共有と過剰共有の両方を戒める**: 「同じ判定・同じ baseline・同じ既定値処理は同じ実装を共有する（過少共有の戒め）。一方で、見た目が同じピッカー UI でも除外規則が操作種別ごとに異なるなら、派生候補一覧を安易に共有しない（過剰共有の戒め）。共有前に『2 操作の制約は本当に同一か』を列挙して確認し、回帰テストで弾く。」
  - 適用: 指定領域の作図結果や妥当性検証（U06／U07）は穴あけと形状編集で共有しうる（過少共有の戒め）が、確定経路（新地物生成 vs 形状編集のみ）は本質的に異なるため安易に共有しない（過剰共有の戒め）。共有部分と非共有部分を列挙して分ける。

- **教訓 5.1 集合演算は複数片を返す前提で扱う**: 「ブーリアン（集合）演算は単一ポリゴンではなく、複数ポリゴン・複数リングを返す前提で扱う。差分・結合・競合解決では返却されたすべての片を変換し、片落とし（配列の先頭だけ採用）を避ける。」
  - 適用: 元末端の穴形成は U06 の差演算で行い、結果が複数片（飛び地に分かれる等）でも全片を保持する。先頭片のみ採用しない。受け入れ基準 8 で固定する。

- **教訓 5.26 編集制約はコマンド確定前にも同じサービスで検証する**: 「編集制約（自己交差・全体重複・階層破綻・禁止条件）は、UI の候補表示だけでなく、コマンド/ユースケースの確定前にも同じサービスで検証する。拒否理由は、ユーザー通知とテスト可能な戻り値の両方で扱う。」
  - 適用: 指定領域の妥当性（3 頂点以上・内部完全包含・非交差・自己交差なし）と、穴あけ後の有効性・階層整合を、UI 候補表示に依存せず本ユニットの確定前に U06／U07／U13 の同じ検証サービスで再検証する。拒否は日本語通知＋機械可読戻り値の両方で返す。受け入れ基準 6 で固定する。

- **教訓 5.20 元に戻す情報は依存データも含めて過不足なく保存する**: 「操作（undo を含む）を元に戻すのに必要な情報は、依存データも含めて過不足なく特定・保存する。ID 等を生成するコマンドは、redo で採番し直さず初回生成 ID を復元する。」
  - 適用: 穴あけは新地物 ID を採番し、元末端の形状・親子関係を変える。undo に必要な依存データ（元末端の旧形状、新地物の全状態、継承した親）を過不足なく保存し、redo では新地物 ID を初回生成値のまま復元する。受け入れ基準 4 で固定する。

- **教訓 5.23 コマンドの execute/undo/redo は対称に通知する**: 「状態変更を伴うコマンドの execute / undo / redo は、同じイベント規約で、touch した全要素へ対称に通知する。直後に手動リフレッシュを書きたくなったら、通知漏れのサインである。」
  - 適用: U13 経由の穴あけコマンドは、touch する全地物（元末端・新地物・継承親の集約地物）へ execute／undo／redo で対称に通知される前提で編集案を組む。確定直後の手動リフレッシュを書かない。

- **教訓 5.11 構造変更操作後の選択は結果から再解決する**: 「結合・分割・移動・削除のように対象 ID や形状が変わる操作では、完了後の選択状態を固定の全クリアで決めない。コマンド結果が『残る要素 ID』『新規要素 ID』『削除された ID』を返し、UI はその結果から選択を再解決する。」
  - 適用: 穴あけ結果は「形状変化して残る元末端 ID」「新規生成された新地物 ID」を返し、UI 層が結果から選択を再解決できるようにする。本ユニットは戻り値の提供までを担い、UI の選択更新は行わない。

- **教訓 5.22 確定まで共有データを破壊的に更新しない**: 「結果が確定するまで、共有キャッシュ/共有データを破壊的に更新しない。検証用の仮データで成功を確認してから反映し、失敗時は追加した要素をすべてロールバックする。」
  - 適用: 穴形成・新地物生成・整合性維持の途中で共有ドメイン状態を破壊更新しない。全検証通過と整合性維持確定を確認してから U13 で一括反映し、拒否時は何も反映しない。

- **教訓 5.18 空配列・空オブジェクトは真値である**: 「空配列・空オブジェクトは真値である。論理和による短絡評価のデフォルト補完に頼らず、型や状態を明示的に判定する。」
  - 適用: 元末端が最上位（親なし＝親 ID 集合が空）の場合の上位領域継承を、短絡デフォルト補完で取り違えず、「親なし」を明示的な状態として扱い新地物も最上位にする。受け入れ基準 2 で固定する。

- **その他の落とし穴**:
  - 新地物の領土リングと元末端の穴リングの **巻き方向（向き規約）** に注意する。U06 が返すリング向きを本アプリの領土リング／穴リングの向き規約へ正規化してから両者へ割り当てる。向きの取り違えは穴の透過判定・点in多角形で対概念矛盾を生む（U06 の向き正規化を信頼し再実装しない。単一の真実源）。
  - 穴は常に透過扱いで塗りを乗せない（FR-21 / FR-100）。元末端に形成した穴領域に新地物が重なって表示されるのは正しい（新地物は独立した末端地物として本土同様に描画される）。穴の透過と新地物の描画は描画層の責務だが、本ユニットが「元末端の穴領域＝新地物の領土領域」という対応を正しく生成することが前提となる。
  - 量子化トレランス（U06）に起因して、新地物の外周と元末端の穴がピクセル単位で完全一致しない可能性がある。前後状態テスト（受け入れ基準 5）の一致判定は U06 のトレランス範囲で行い、厳密一致を要求しない。
  - 継承した親が集約地物の場合、集約地物の形状＝下位領域の和（FR-35）の不変条件は、元末端＋新地物の和が元末端の元形状に等しいことで維持される。この階層整合の最終検証は U13 の整合性維持プロセスへ委ね、本ユニット内で集約形状を再計算しない（単一の真実源）。
  - クリーンルーム原則（開発ガイド §3.1）: 本仕様・実装ともに過去版・他プロダクト・外部の既存実装に言及せず、必要な制約は v4 の要件・方針として直接記述・参照する。
