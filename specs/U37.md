## 1. 目的

本アプリに **測量モード** を提供する。測量モードでは、ユーザーが地図上を 2 点クリックすると、その 2 点間の距離を **正距円筒図法に基づく距離（地図平面上の距離）と大円距離（球面上の最短経路距離）の双方** で計算して表示する（FR-14）。世界端（地図の東端・西端）をまたぐ測定線は折り返して表示し、地図を一周する巨大な線として分断・誤表示しない（FR-14）。

加えて次を満たす。

- **測量線の永続表示（一時的・非保存）**: 測量線は測量モードを解除しても残り、明示的にクリアするまで表示され続ける。複数本を同時に表示でき、クリアボタンで一括消去する。大円距離に基づく最短経路の線を描画する。これらの測量線は **プロジェクトデータには保存されない一時的な表示** である（FR-15）。
- **クリック地点の緯度経度表示と一時マーカー**: クリックした地点の緯度経度を **度分秒形式と十進形式の両方** で表示し、その地点に一時的なマーカーを表示する（FR-16）。
- **一時 UI 状態の全経路破棄**: 測量途中（1 点目クリック後、2 点目未確定）の進行中ドラフト・プレビュー・ホバー中の緯度経度表示などの一時 UI 状態を、確定・キャンセル・クリア・ツール切替・モード切替（測量モードの解除を含む）のすべての経路で明示的に破棄する（開発ガイド 教訓 5.2）。

測量モードは閲覧系の補助機能であり、ドメインの真実（地物・歴史の錨・ツリー）を一切変更しない。整合性維持プロセス・アンドゥ/リドゥの対象にもならない（測量は編集操作ではない）。

## 2. スコープ

### 2.1 やること

- **測量モードの提供（FR-14）**
  - 測量モードという状態を 1 つ提供する。測量モードは追加モード・編集モードとは別軸の補助モードであり、有効化すると地図上のクリックが「測量用の点打ち」として解釈される。
  - 測量モードの有効化/無効化（解除）の入口を、UI シェル（U20）が提供するツールバー/メニューの枠に結線する（後述 §4 の依存連携）。本ユニットはモードの状態と挙動を担い、ツールバーのボタン外観そのものの最終配置は U20 の枠組みに乗せる。

- **2 点クリックによる距離計測（FR-14）**
  - 測量モードで地図上を 1 点クリックすると 1 点目（始点）が確定し、続けてもう 1 点クリックすると 2 点目（終点）が確定して 1 本の測量線が成立する。
  - 成立した測量線について、始点・終点の 2 点間の **正距円筒距離(km)** と **大円距離(km)** の双方を計算して表示する（計算は U04 の測地計算モジュールへ委譲する。本ユニットで距離公式を再実装しない）。
  - 1 点目クリック後・2 点目未確定の間は、カーソル（ホバー）位置を仮の終点とした **プレビュー測量線とプレビュー距離** を仮表示する（確定スタイルと区別した一時表示。教訓 5.2）。

- **世界端をまたぐ測定線の折り返し表示（FR-14）**
  - 始点と終点が世界端（地図の東端・西端）をまたぐ場合でも、測量線は **最短側へ折り返して連続表示** し、地図を一周する巨大な線として分断・誤表示しない。
  - 距離計算における経度差の最短折り返し（±360 度正規化）は U04 が担う。本ユニットは、折り返した測量線・大円最短経路線を **無限横スクロール表示と整合する形で描画** する（端ラップ表示で世界端をまたいでも途切れず連続して見える。描画の端ラップ展開は U17 の描画基盤に委譲し、本ユニットで ±360 度オフセット複製・周期境界判定を再実装しない。単一の真実源）。

- **測量線の永続表示・複数同時・クリア（FR-15）**
  - 成立した測量線は **測量モードを解除しても表示され続ける**。明示的にクリアするまで消えない。
  - 測量線を **複数本同時に保持・表示** できる。
  - **クリアボタン**（測量結果の一括消去）を提供する。クリアで全測量線・全一時マーカー・進行中ドラフトをすべて消去する。
  - 測量線は **大円距離に基づく最短経路の線** を描画する（FR-15）。大円最短経路（測地線）を地図平面上に投影した曲線を、十分な分割数の折れ線として近似描画する。あわせて正距円筒距離に対応する直線（地図平面上の直線）も区別可能なスタイルで描けるようにするが、FR-15 が明示する必須描画対象は「大円距離に基づく最短経路の線」である。
  - これらの測量線・マーカーは **プロジェクトデータに保存されない一時的な表示** である（永続化対象に含めない。後述 §2.2・§4）。

- **クリック地点の緯度経度表示と一時マーカー（FR-16）**
  - クリックした地点（始点・終点・必要に応じてホバー中の地点）の緯度経度を **度分秒形式（例: 北緯 35°41′22″ / 東経 139°45′00″ 相当の表記）と十進形式（例: 35.6894, 139.7500 相当）の両方** で表示する。
  - 度分秒・十進の双方の表記文字列を生成する純粋関数を提供する（負値=南緯/西経の扱い、世界端ラップ後の代表区間への正規化を含む。後述 §4.4）。
  - クリック地点に **一時的なマーカー** を表示する。マーカーは測量線と同じく一時的（非保存）であり、クリアで消える。

- **一時 UI 状態の全経路破棄（教訓 5.2）**
  - 測量途中ドラフト（1 点目確定済み・2 点目未確定）、プレビュー線、プレビュー距離、ホバー中の緯度経度表示などの一時 UI 状態を、次のすべての経路で破棄する。
    - 測量の **確定**（2 点目クリックで 1 本成立した直後、次の測量に向けて進行中ドラフトをリセット）。
    - **キャンセル**（Escape 等での測量途中の取りやめ）。
    - **クリア**（クリアボタン押下）。
    - **ツール切替**（測量モード内の別ツールへ切替する場合）。
    - **モード切替**（測量モードの解除、追加/編集モードへの切替）。
  - ただし「確定済みの測量線・マーカー（クリアまで残る永続表示分）」と「測量途中の一時ドラフト」を区別し、モード解除では **一時ドラフトのみ破棄し、確定済み測量線は残す**（FR-15）。クリアでは両方消す。この区別を取り違えないこと（後述 §6 の落とし穴）。

- **テストの同時実装（開発ガイド §1.9）**
  - 緯度経度フォーマット・測量線の状態遷移（点打ち→確定→クリア）・大円最短経路の折れ線近似・世界端ラップ折り返しなど、UI から切り出せるロジックを純粋関数として分離し、Vitest 単体テスト・fast-check プロパティテストを実装と同時に書く。

### 2.2 やらないこと

- **距離・面積・大円距離の数値計算そのもの**（正距円筒距離・大円距離・経度差の最短折り返し正規化）。これは U04 の責務。本ユニットは U04 の公開関数へ座標を渡して結果を表示するのみで、距離公式・haversine・±360 度正規化を再実装しない（単一の真実源。技術方針 2.9）。
- **ワールド↔スクリーン座標変換・カメラ操作・無限横スクロールの端ラップ描画基盤**。これは U17（`MapRenderer` と VTransform）の責務。本ユニットは U17 の変換・描画契約を用いて測量線・マーカーを描き、座標変換や ±360 度オフセット複製を再実装しない。
- **測量線・マーカーのプロジェクトデータへの保存／読み込み**。測量結果は一時的・非保存（FR-15）であり、`.tmap` の永続化対象に **含めない**。永続化スキーマ（Zod）へ測量線フィールドを追加しない。
- **地物（点・線・面）の追加・編集・選択・削除**、共有頂点、ツリー階層操作、整合性維持プロセス、競合解決、アンドゥ/リドゥ。測量はドメインを変更しない補助機能であり、これらに一切関与しない。
- **線情報の長さ計測・面情報の面積計測の UI**（FR-19 / FR-20）。測量モードは「任意の 2 点間距離・緯度経度の参照」専用であり、地物としての線・面の計測 UI は別ユニットの責務。本ユニットは地物を生成しない。
- **グリッド（緯線・経線）の描画・設定**（FR-13）、ベースマップ表示（FR-03/04）、表示経度シフト UI（FR-12）。
- **UI シェル（ツールバー・メニュー・サイドバーの枠組み）そのものの構築**。これは U20 の責務。本ユニットは U20 が用意したツール枠・パネル枠・状態管理基盤に測量機能を差し込む。
- **暦・時間計算・現在時刻に依存する処理**。測量は時間に依存しない空間計測であり、年・月・日や歴史の錨を一切参照しない。

## 3. 依存（dependsOn）

本ユニットは以下の公開インタフェース契約に依存する。依存ユニットの公開型（関数名・引数・戻り値型・状態キー）は偶然の一致に頼らず、共有型を import して両側テストで固定する（開発ガイド 教訓 5.33 / 5.34）。依存ユニットの API が未確定の段階では、本仕様に記す入出力契約に沿った境界インタフェース（adapter）を本ユニット内に先に定義し、その型に対して操作フローと単体テストを実装し、依存先確定後に接続する。

- **U17 — `MapRenderer` インタフェースと Canvas カメラのワールド↔スクリーン VTransform**
  - スクリーン座標（クリック位置）↔ワールド座標（経度・緯度）の双方向変換を U17 の VTransform から得る。クリック位置のワールド座標化、測量線・マーカーの描画位置のスクリーン化に用いる。
  - 測量線・マーカー・距離ラベル・緯度経度ラベルは U17 の **地物バッチ契約** に「描画すべきものの記述（ワールド座標＋視覚属性）」として渡し、世界端をまたぐ端ラップ表示・ズーム非依存の一定サイズ表示（マーカー・ラベルのサイズ固定、FR-17）は U17 の描画基盤に委譲する。本ユニットで端ラップ展開・座標変換・一定サイズ算出を再実装しない。
  - 着手前に U17 の公開する「ワールド↔スクリーン変換関数」「地物バッチに渡せる描画記述の型」「ヒットテスト（クリック位置→ワールド座標）の入口」をソースで確認し、再利用する（開発ガイド §2.11 既存性の主張は実在確認してから書く）。

- **U04 — 測地計算モジュール（距離・面積・大円距離）**
  - 2 点間の **正距円筒距離(km)** と **大円距離(km)** を U04 の公開関数（正距円筒距離・大円距離の双方を算出する関数）へ測地パラメータ `geoParams = { equatorKm, flattening }`（赤道長・扁平率, FR-109）とともに渡して取得する。
  - U04 は世界端ラップ（±360 度）をまたぐ 2 点間距離を折り返しで正しく扱う（経度差を絶対値最小の符号付き差に正規化する）。距離の折り返し正規化は U04 を **単一の真実源** として用い、本ユニットで再実装しない。
  - 大円最短経路線の折れ線近似に必要な中間点（測地線上の補間点）の算出が U04 に用意されていれば再利用する。無ければ §4.3 の方針に従い本ユニットで補間点列を生成し、各区間長の整合（折れ線長 ≒ U04 の大円距離）をテストで固定する。
  - 赤道長(km)・扁平率はプロジェクト設定値（FR-05/FR-109）であり、本ユニットは設定ストア（U20 が前提とする状態管理基盤経由）から現在の赤道長・扁平率を `geoParams` として取得して U04 へ渡す。これらを本ユニットでハードコードしない。

- **U20 — アプリレイアウトシェルとモード/ツールバー骨格**
  - 測量モードの有効化/無効化ボタン、クリアボタン、距離・緯度経度の表示先パネル（または地図上オーバーレイの器）を、U20 が用意したツールバー枠・パネル枠・オーバーレイ層に差し込む。
  - 測量モードという状態（および測量途中ドラフト等の一時 UI 状態）は、U20 が前提とする **UI/セッション状態の薄いストア**（技術方針 §2.5 の状態管理基盤）に置く。ドメインの真実とは分離された UI/セッション状態として扱う。測量結果（測量線・マーカー）も一時的な UI/セッション状態であり、永続化されないことを状態の置き場所で明確にする。
  - U20 が提供する「重なる UI の入力層」設計（教訓 5.14）に従い、測量結果オーバーレイ・距離ラベルが中央マップのクリック入力（測量の点打ち）やパン操作を奪わない層構造に乗せる。
  - U20 が提供する「一時 UI 状態の全経路破棄」「表示専用一括無効化」の規律に従い、測量モードのモード切替時破棄・表示専用時の扱いを U20 の枠組みに整合させる。

> 注: 測量はドメインを変更しないため、本ユニットは `domain` 層の地物・錨・ツリーを書き換える経路を持たない。距離・緯度経度の計算ロジックは純粋関数として `domain` 層（U04 と同じ純粋計算側）に置き、測量モードの状態・入力ハンドリング・描画記述の組み立ては UI/操作層に置く（後述 §4.1）。

## 4. 実装方針（技術方針に沿う）

### 4.1 配置と層

- **純粋計算（`domain` 層）**: 緯度経度の度分秒/十進フォーマット、大円最短経路の補間点列生成、世界端ラップ後の代表区間正規化など、副作用のないロジックは `domain` 層（フレームワーク非依存・純粋）に置き、Vitest 単独で実行できるようにする。U04 の距離計算を呼び出すアダプタもここに置く。
- **状態・入力ハンドリング・描画記述の組み立て（UI/操作層）**: 測量モードの状態機械（アイドル→1 点目確定→2 点目確定/キャンセル）、クリック/ホバーのポインタ入力受理、U17 への描画記述（バッチ）の組み立ては UI/操作層に置き、`domain` の純粋ロジックへ依存させる。依存方向は内向き固定（`domain` へ）（技術方針 2.13）。
- **React からの分離**: 測量線・マーカー・プレビュー線は高頻度に再描画されうる（ホバー追従のプレビュー）。これらの描画状態を React state に持たせて毎回再レンダリングしない。描画状態は U20 の状態管理基盤（Zustand 相当）と命令的描画（U17 経由）に置き、React は周辺 UI（距離パネルの数値表示・モードボタン・クリアボタン）のみを管理する（技術方針 §2.3）。ホバープレビューの追従は描画層側で処理し、React 再レンダリングサイクルに乗せない。

### 4.2 測量モードの状態機械（教訓 5.8 / 5.7 / 5.2）

- 測量の点打ちフローを明示的な状態機械として表現する。
  - **アイドル**（測量モード有効・始点未確定）→ クリックで **1 点目確定**（始点保持、以降ホバーでプレビュー線・プレビュー距離・プレビュー緯度経度を更新）→ もう 1 点クリックで **2 点目確定**（1 本の測量線が成立し永続表示リストへ追加。状態はアイドルへ戻り、次の測量に備えて一時ドラフトを破棄）。
- **完了トリガーの実装**（教訓 5.7）: 「2 点目クリックで 1 本成立」という完了トリガーを UI のクリックハンドラから必ず呼ぶ。ロジックがあっても UI から呼ばれず機能しない状態を作らない。
- **押下→（移動）→確定の全パス保証**（教訓 5.8）: 測量はクリック（押下→解放が同位置）で点を打つ操作である。1 点目クリックで設定した進行中状態は、2 点目クリックでの確定・Escape でのキャンセル・モード解除のいずれかで必ず解除する。ドラッグ（押下したまま移動）でパンと競合しないよう、測量の点打ちは「クリック（移動なし）」で確定し、ドラッグはパン操作へ渡す層設計とする（U20 の入力層と整合）。
- **一時ドラフトの全経路破棄**（教訓 5.2）: 1 点目確定後の始点・プレビュー線・プレビュー距離・プレビュー緯度経度を、確定・キャンセル・クリア・ツール切替・モード切替の全経路で破棄する。確定済みの測量線リストとは別の状態スロットに一時ドラフトを保持し、破棄経路を取り違えない。

### 4.3 距離計算と大円最短経路線（FR-14 / FR-15）

- 2 点間の正距円筒距離・大円距離は U04 の公開関数へ「始点（経度・緯度）・終点（経度・緯度）・赤道長(km)」を渡して取得する。両方の値を表示する（FR-14 が双方の表示を要求）。
- **大円最短経路線の描画**（FR-15）:
  - 大円（測地線）上を始点から終点まで等間隔（中心角に対して等分）に補間した点列を生成し、各補間点をワールド座標（経度・緯度）として U17 の描画基盤へ渡し、折れ線として描く。これにより正距円筒図法の地図平面上では大円が曲線（高緯度側へ膨らむ弧）として描かれる。
  - 補間分割数は弧長に応じて適応的に決め、曲線が視覚的に滑らかになる十分な数とする（短距離では少数、長距離では多数）。
  - 補間点の生成は球面線形補間（slerp 相当）で行う。U04 に大円中間点関数があれば再利用し、無ければ本ユニットの `domain` 層に純粋関数として実装し、「補間折れ線の総長 ≒ U04 の大円距離（誤差内）」をテストで固定する（定義のドリフト防止）。
  - 正距円筒距離に対応する線（地図平面上の直線）も描けるようにし、大円最短経路線と区別可能なスタイルにする。FR-15 の必須描画対象は大円最短経路線であることを満たす。
- **世界端をまたぐ折り返し**（FR-14、技術方針 R3）:
  - 経度差の最短折り返し（±360 度正規化）は U04 の距離計算が担う。本ユニットは描画にあたり、始点・終点・大円補間点列を **最短側で連続する経度列** として構成する（直前点との最短差を累積して経度をアンラップ＝連続化する）。これにより測量線・大円線が世界端をまたいでも 1 本の連続した線として描かれ、地図を一周する分断・巨大表示にならない。
  - アンラップ後の経度列を U17 の描画基盤へ渡せば、U17 の端ラップ表示（±360 度オフセット複製）により、無限横スクロールのどの位置でも線が途切れず見える。±360 度オフセット複製・周期境界判定は U17 に委譲し、本ユニットで再実装しない（単一の真実源、技術方針 R3）。

### 4.4 緯度経度の度分秒/十進表示（FR-16）

- クリック地点（始点・終点・必要に応じてホバー地点）のワールド座標（経度・緯度）を、**度分秒形式と十進形式の両方** の表示文字列へ変換する純粋関数を `domain` 層に実装する。
  - **十進形式**: 緯度・経度をそれぞれ十進度で表示する（小数桁数は表示に十分な精度で固定。負値は南緯/西経として符号または方位表記で扱う）。
  - **度分秒形式**: 十進度を度・分・秒へ分解して表示する（分・秒の桁あふれ＝60 への繰り上がり、丸め時の繰り上がりを正しく処理する）。北緯/南緯・東経/西経の方位を日本語表記で付す（FR-115 日本語 UI）。
- **世界端ラップ後の代表区間正規化**: 経度は連続スカラー（例 +540 度など範囲外）でクリックされうるため、表示前に代表区間（例 `[-180, +180)` または一貫した基本範囲）へ周期正規化してから度分秒/十進へ変換する。境界（ちょうど ±180 度・0 度）での扱いを 1 つに統一する。緯度は周期性を持たないため経度の周期処理を流用しない（教訓 5.30 過剰共有の戒め）。代表区間正規化に U04/U17/U05 系の既存正規化関数があれば再利用し、本ユニットで二重実装しない（単一の真実源）。
- **一時マーカー**: クリック地点に一時マーカーを表示する描画記述を U17 の描画基盤へ渡す。マーカーはズーム非依存の一定サイズ（FR-17）で描かれる（サイズ固定は U17 の責務）。マーカーは測量線と同じく一時的（非保存）で、クリアで消える。

### 4.5 一時性・非保存（FR-15）

- 測量線・一時マーカー・距離結果・緯度経度結果は、すべて **一時的な UI/セッション状態** として保持し、`.tmap` の永続化スキーマ（Zod）・保存内容（FR-103）に含めない。保存/読み込みの往復で測量結果が消える（保存されない）ことを明確にし、永続化層へ測量関連フィールドを追加しない。
- 複数本の測量線を保持できるよう、確定済み測量線をリスト（配列）として保持する。クリアでリストを空にする。新規プロジェクト開始・ファイル読み込み時など UI 文脈が切り替わる場面でも測量結果は引き継がない（一時表示として破棄）方針とし、U20 の状態初期化文脈と整合させる（教訓 5.36 と整合する範囲で、測量結果は非保存の一時状態として扱う）。

### 4.6 文言とエラー処理

- 距離単位（km）、緯度経度の方位（北緯/南緯/東経/西経）、モード名・クリアボタン・操作ガイドの文言はすべて日本語で、U20 の文言定数モジュールへ集約する（FR-115、技術方針 5.5）。i18n 抽象は設けない。
- 計測・フォーマット時の想定外（NaN・退化入力＝同一 2 点など）はユーザーに破綻表示を見せず、同一 2 点は距離 0km・度分秒/十進ともに当該地点の表記として扱う（例外を投げない）。想定外の内部不整合は「開発者へ報告してください」案内付きで扱う（FR-117）。

### 4.7 テスト（実装と同時に書く。開発ガイド §1.9）

- **Vitest 単体テスト（`domain` 純粋ロジック）**:
  - 緯度経度の度分秒/十進フォーマット: 代表値（赤道・本初子午線・北緯/南緯・東経/西経、負値、分秒の繰り上がり境界、丸め境界）で期待文字列を固定する。
  - 大円最短経路の補間点列: 補間折れ線の総長が U04 の大円距離と誤差内一致すること。補間点が始点・終点を端点に持つこと。
  - 経度の代表区間正規化: 範囲外経度（±360 度を超える連続スカラー）が代表区間へ正しく写り、境界値の扱いが一貫すること。
  - 測量状態機械: アイドル→1 点目→2 点目確定で測量線が 1 本増えること。Escape/クリア/モード切替で一時ドラフトが破棄され確定済みリストが（クリア以外では）保持されること。
- **fast-check プロパティテスト（NFR 5.8）**:
  - 距離の表示が U04 の対称性（`dist(a,b)=dist(b,a)`）・非負性を反映すること（U04 への委譲が正しいこと）。
  - **ラップ不変性**: 始点・終点の全経度に一律 `+360k`（整数 k）を加えても、表示される正距円筒距離・大円距離・代表区間正規化後の緯度経度表記が（誤差内で）変わらないこと。**これが世界端ラップを折り返しで正しく扱えていることの中核プロパティ**。
  - **世界端境界ケース**: 始点を東端近傍（例 +179.x 度）、終点を西端近傍（例 −179.x 度）に置いたとき、距離が「素朴差 359 度相当」ではなく「折り返し 1 度相当」になり、測量線（アンラップ経度列）が分断しないこと。
  - 度分秒⇄十進の整合: 度分秒へ分解して再合成すると元の十進度に（誤差内で）戻ること。
- **E2E（必要に応じて）**: 測量モード有効化→2 点クリックで距離（正距円筒・大円双方）と緯度経度（度分秒・十進双方）が表示→測量モード解除しても測量線が残る→もう 1 本測量→クリアで全消去、の通し挙動。とくに「測量→測量モード解除→測量線が残存」「クリア→全消去」「測量途中→キャンセル/モード切替→一時ドラフトのみ破棄・確定済みは残存」を確認する（教訓 5.2 の検出観点）。

## 5. 受け入れ基準（テスト可能な形で列挙）

実装者は、以下すべてが対応するテスト（`domain` 純粋ロジックの Vitest／fast-check、状態機械のテスト、必要に応じて E2E）で緑になるまで本ユニットを「完了」にしない。

1. **AC-1（正距円筒距離と大円距離の双方を表示）**（FR-14）: 測量モードで 2 点クリックすると、その 2 点間の **正距円筒距離(km) と大円距離(km) の双方** が計算され表示される。計算は U04 へ委譲され、本ユニットで距離公式を再実装していない。代表ケースで双方の値が U04 の戻り値と一致することをテストで確認する。

2. **AC-2（世界端をまたぐ測定線の折り返し・非分断）**（FR-14）: 始点と終点が世界端（東端・西端）をまたぐ場合でも、距離が最短側の折り返しで算出され、測量線・大円最短経路線が **1 本の連続した線として折り返し表示され分断しない**。全経度へ `+360k` を加えても距離・表示が不変であること、東端近傍↔西端近傍の 2 点で距離が折り返し最短側になることをテストで確認する。

3. **AC-3（測量線の永続表示・複数同時・クリア・大円最短経路線）**（FR-15）: 成立した測量線は **測量モードを解除しても残り、クリアするまで表示され続ける**。複数本を同時に保持・表示できる。クリアボタンで全測量線・全一時マーカー・進行中ドラフトが一括消去される。測量線として **大円距離に基づく最短経路の線** が描画され、その折れ線総長が U04 の大円距離と誤差内一致する。測量線・マーカーは **プロジェクトデータに保存されない一時的な表示** であり、永続化スキーマに含まれない（保存/読み込み往復で測量結果が永続化されない）。

4. **AC-4（緯度経度の度分秒/十進両方と一時マーカー）**（FR-16）: クリックした地点の緯度経度が **度分秒形式と十進形式の両方** で表示され、その地点に **一時的なマーカー** が表示される。度分秒/十進の相互整合（分解→再合成で元値に戻る）、方位（北緯/南緯/東経/西経）の日本語表記、分秒の繰り上がり境界が正しいことをテストで確認する。マーカーはクリアで消える一時表示である。

5. **AC-5（一時 UI 状態の全経路破棄）**（教訓 5.2）: 測量途中の一時ドラフト（始点・プレビュー線・プレビュー距離・プレビュー緯度経度）が、**確定・キャンセル・クリア・ツール切替・モード切替（測量モード解除）のすべての経路で破棄** され、次回操作へ暗黙に引き継がれない。とくにモード解除では一時ドラフトのみ破棄し確定済み測量線は残す（クリアでは両方消す）区別が守られる。「測量途中→キャンセル→再測量」「測量途中→確定→再測量」「測量途中→モード切替→再測量」の連続でドラフトが残らないことをテストで確認する。

6. **AC-6（層分離・非ドメイン・非保存・依存委譲）**: 緯度経度フォーマット・大円補間・代表区間正規化が `domain` 層の純粋関数として Vitest 単独で実行できる。距離計算は U04、座標変換・端ラップ描画・一定サイズ表示は U17、UI 枠・状態管理基盤・入力層は U20 へ委譲し、これらを本ユニットで再実装していない。測量はドメインの真実（地物・錨・ツリー）を変更せず、整合性維持プロセス・アンドゥ/リドゥの対象にならない。strict 全有効でビルドが通る。

## 6. 注意点・既知の落とし穴（開発ガイドの教訓を踏まえる）

着手前に、以下の教訓を節番号・見出し・本文ごと直接引用し、今回の実装判断へどう適用するかを「適用:」として 1 文以上で明示してから着手すること（開発ガイド §1.6 AI 作業開始ゲート）。

- **教訓 5.2「一時的 UI 状態は全経路で破棄する」**
  - 適用: 測量途中ドラフト（始点・プレビュー線・プレビュー距離・プレビュー緯度経度・ホバー表示）を、確定・キャンセル・クリア・ツール切替・モード切替（測量モード解除）の全経路で破棄する。確定済みの測量線リスト（クリアまで残る）と一時ドラフトを別スロットに分離し、モード解除では一時ドラフトのみ破棄・確定済みは残し、クリアでは両方消す区別を取り違えない。検出: 「測量途中→キャンセル→再測量」「測量途中→確定→再測量」「測量途中→モード解除→再測量」を E2E/状態機械テストで確認する（受け入れ基準 5）。

- **教訓 5.7「完了トリガーを必ず実装する」**
  - 適用: 「2 点目クリックで測量線 1 本成立」という完了トリガーを UI のクリックハンドラから必ず呼ぶ。ロジック側に成立処理があっても UI から呼ばれなければ測量が完了しない。クリアボタンも同様に UI からの呼び出し経路を実装する（受け入れ基準 3）。

- **教訓 5.8「押下→移動→解放シーケンスを全パスで保証する」**
  - 適用: 測量はクリック（押下→解放が同位置）で点を打つ。1 点目クリックで設定した進行中状態は 2 点目クリック確定・Escape キャンセル・モード解除で必ず解除する。ドラッグ（移動あり）はパン操作へ渡し測量の誤確定を防ぐ。移動が発生しないクリックの考慮漏れを作らない。

- **開発ガイド §4「単一の真実源」／教訓 5.30「過少共有と過剰共有の両方を戒める」**
  - 適用: 距離計算・経度の最短折り返し（±360 度正規化）は U04 を唯一の窓口とし、座標変換・端ラップ描画・一定サイズ表示は U17 を唯一の窓口とする（過少共有の戒め＝再実装しない）。一方、経度の周期正規化を緯度（周期性なし）へ流用しない（過剰共有の戒め）。赤道長は設定ストアから取得し本ユニットで固定値を持たない。

- **技術方針 R3 ／ FR-14 ／ FR-07 世界端ラップ**
  - 適用: 測量線・大円最短経路線の経度列は直前点との最短差を累積してアンラップ（連続化）してから描画へ渡し、東端↔西端をまたぐ線が「地図を一周する巨大値・分断」にならないようにする。±360 度オフセット複製・周期境界判定は U17 へ委譲する。回帰防止として「全経度 +360k で距離・表示不変」「東端近傍↔西端近傍で折り返し最短」のプロパティ/境界テストを必須にする（受け入れ基準 2）。

- **教訓 5.25「仕様が限定した対象範囲を実装で広げない」**
  - 適用: 測量モードは「任意 2 点間の距離・緯度経度の参照」と「一時的・非保存の測量線/マーカー」に閉じる。「自然な拡張」を理由に、測量結果の永続化・地物（点/線/面）化・面積計測・編集操作・アンドゥ対象化へ広げない。FR-15 の「保存はされない一時的なもの」を引用して止まる。

- **教訓 5.18「空配列・空オブジェクトは真値である」**
  - 適用: 「測量線 0 本」「始点のみ確定（終点未確定）」「補間点列が端点のみ」などを論理和の短絡デフォルト補完で誤判定しない。件数・有無を明示判定し、空状態（測量線なし・進行中なし）を正しく描画スキップ/距離非表示として扱う。

- **教訓 5.14「重なる UI は入力を受ける層も同時に設計する」（U20 の入力層と整合）**
  - 適用: 測量結果オーバーレイ・距離ラベル・緯度経度ラベルが、中央マップのクリック入力（測量の点打ち）・パン操作を奪わない層構造に乗せる。ラベル等の透明背景層が背面のクリック/パンを覆わないことを、重なった状態の操作テストで確認する。

- **教訓 5.33 / 5.34「層をまたぐ契約・コンポーネント間契約を型で明示し両側テストで固定する」**
  - 適用: U04（距離関数）・U17（変換/描画記述/ヒットテスト）・U20（状態キー・ツール枠・文言定数）の公開契約を共有型で import し、関数名・引数・戻り値構造・状態キーを両側テストで固定する。依存先 API が未確定なら本ユニット内に境界インタフェース（adapter）を切って未確定部分を局所化し、確定後に接続する。

- **教訓 5.36「プロジェクト設定とアプリ全体設定の境界を先に定義する」（非保存方針との整合）**
  - 適用: 測量結果は一時的・非保存の UI/セッション状態であることを置き場所で明確にし、永続化（FR-103）・自動バックアップ対象・dirty 状態へ混入させない。新規プロジェクト開始・ファイル読み込みで測量結果を引き継がず破棄する（保存対象でないため dirty を立てない）。

- **数値・退化入力の防御**
  - 適用: 同一 2 点・極小距離・極端経度（連続スカラー大値）でも NaN/例外を出さず、距離 0km・当該地点の緯度経度表記を返す。度分秒の分秒繰り上がり・丸め境界・代表区間境界（±180 度・0 度）を 1 つの定義に固定し、テストで固定する。浮動小数比較は許容誤差で行う。

- **クリーンルーム原則（開発ガイド §3.1）**
  - 適用: 本仕様・実装・テスト名で過去版や外部の既存実装に言及しない。必要な制約はすべて v4 自身の要件（FR-14/15/16 ほか）・技術方針として直接記述・参照する。

- **失敗の教訓化（開発ガイド §1.5 / §1.9）**
  - 適用: 実装中に既存教訓で説明できない不具合の根本原因が見つかったら、完了前に開発ガイド §5 へ新教訓を追記し、回帰テストを同一作業内で追加する。

- **FR-05**（must）/ **FR-109**（should）: 正距円筒図法前提と赤道長(km)設定。本ユニットは設定ストアの赤道長を U04 へ渡す。
- **FR-07**（must）: 横方向の無限スクロール。世界端をまたぐ測量線の折り返し表示と整合（U17 の端ラップ表示へ委譲）。
- **FR-17**（should）: ズーム非依存の画面上一定サイズ表示。一時マーカー・ラベルのサイズ固定は U17 の描画基盤へ委譲。
- **FR-115**（must）/ **FR-117**（should）: 日本語のみ UI とユーザーフレンドリーな日本語エラーメッセージ。距離単位・方位・文言は日本語で定数集約。
- 関連非機能要件: NFR 5.1（ホバープレビューの高頻度更新を React 再レンダリングに乗せず描画層で処理）、NFR 5.8（緯度経度フォーマット・大円補間・代表区間正規化を純粋関数として境界網羅テスト可能にする）。
- 背景根拠: 技術方針 2.9（測地計算は U04 の自前純粋関数）、2.4（地図描画は U17 の `MapRenderer`）、2.3/2.5（地図描画と React 再レンダリングの分離・UI/セッション状態の薄いストア）、R3（無限横スクロール・経度シフトと世界端ラップの整合）。

## 8. 実装の進め方（推奨手順）

開発ガイド §1.9 の順序に従う。

1. 機能宣言 ＋ 本書該当節の仕様引用。
2. 関連教訓（§6 に列挙）の引用・適用宣言（AI 作業開始ゲート）。
3. 依存先（U04 の距離関数・大円補間、U17 の変換/描画記述/ヒットテスト、U20 の状態管理基盤/ツール枠/文言定数）の公開契約をソースで実在確認し、再利用 or adapter 定義を決定（開発ガイド §2.11）。
4. `domain` 層の純粋ロジック（緯度経度フォーマット・大円補間点列・代表区間正規化・U04 呼び出しアダプタ）を実装し、Vitest ＋ fast-check を同時に追加。
5. 測量モードの状態機械（アイドル→1 点目→2 点目確定/キャンセル）と一時ドラフトの全経路破棄を実装し、状態機械テストを追加。
6. U17 への描画記述（測量線・大円最短経路線・一時マーカー・距離/緯度経度ラベル）の組み立てを実装し、端ラップ・一定サイズ表示は U17 へ委譲。
7. U20 のツール枠・パネル枠・クリアボタン・入力層へ結線し、距離（正距円筒・大円双方）と緯度経度（度分秒・十進双方）の日本語表示を配置。
8. 非保存（永続化スキーマに含めない）を確認。E2E で通し挙動（測量→モード解除で残存→複数本→クリアで全消去→途中キャンセル/モード切替で一時のみ破棄）を確認。
9. 全テスト緑 → strict ビルド確認。
10. 状態文書（現状.md / 実装済み.md）を役割分担規約（開発ガイド §2.1）に従って更新。
11. コミット（ローカルのみ、push しない。メッセージは日本語本文＋ Conventional Commits の type）。
