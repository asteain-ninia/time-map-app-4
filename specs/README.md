# specs/ — 着手指示書（凍結、2026-08-16）

このディレクトリの U01〜U43 は、**2026-06-20 に一括で書かれたユニット単位の着手指示書**である。
「これから何をどう作るか」を実装者に渡すための書き置きであり、**出来上がったものの説明ではない**。
**2026-08-16 をもって凍結した。今後ここへ新規の追記はしない。**

## 現在の正はどこにあるか

| 知りたいこと | 見る場所 |
| --- | --- |
| 何を満たすべきか（仕様） | `docs/要件定義書.md` |
| どう実現しているか（設計判断） | `docs/技術方針.md` |
| いま何が未解決か | `docs/現状.md` |
| いつ何を実装したか | `docs/実装済み.md` |
| 実際にどう動くか | ソースコード（`src/`） |

**このディレクトリの記述と `docs/` が食い違ったら、`docs/` が正**である。
仕様を確かめる目的でここを読んではならない。読んでよいのは「着手当時、何をどう作ろうとしていたか」を
知りたいときだけである。

## なぜ書き換えずに凍結するのか

着手当時の指示という一次資料としての価値があり、書き換えるとその価値が失われる（`.autopilot/` と同じ扱い）。
`docs/` 側が現在の正として整備済みであるため、`specs/` を現役の仕様として維持する必要もない。

## 現行と食い違っている箇所（既知）

網羅ではない。凍結時点で把握しているものを挙げる。詳細と据え置き理由は `docs/現状.md` B4 にある。

- **保存ファイルの拡張子が `.tmap`**（U14 / U15 / U16 / U37 / U38 / U39 / U42）。2026-08-15 に `.gimoza` へ改称した。
- **地球の地名「本初子午線」「太平洋」**（U17 / U18 / U37 / U40 の 13 行。うち 10 行が U18）。2026-07-12 に経度の値（0 度経線 / 0 度中心 / 180 度中心）へ言い換えた。架空世界の地図なので地球の固有名詞は使わない。現行 UI のラベルは「0 度中心」「180 度中心」であり、指示書どおりに実装すると文言が逆戻りする。
- **背景地図をラスター画像前提で規定している**（U18）。2026-08-09 にプリセット出界図はベクターへ移行した（`docs/技術方針.md` §6.7）。
- **アクティブ地物の強調が「固定のシアン」**（U22）。2026-07-25 に「その地物の選択色」へ改めた（FR-82）。
- **サイドバーが 3 区画（イベント一覧・階層ツリー・プロパティ）**（U20 / U41）。現行は「一覧」「プロパティ」の 2 区画で、一覧が両方の役割をモード切替で兼ねる（FR-111）。
- **頂点マーカー表示上限に触れていない**（U24）。実際にはハンドル経路が上限を持つ（FR-110）。
- **参照先のパスが旧開発機の絶対パス**（U11 / U26 / U28 / U30 / U36 / U38 / U42 の冒頭）。2026-08-06 に本機へ移設済みで、この経路は存在しない。リポジトリからの相対パス（`docs/要件定義書.md` 等）に読み替えること。
- **U28 の「新規上位領域を作成する」枝は UI から到達できない**。2026-08-11 の全数照合で確定した未実装（`docs/現状.md` R2 / R3）。仕様と実装の乖離がこのディレクトリで最も大きい。

## とくに注意（作ると退行するもの）

上の食い違いは「古い呼び名・古い前提」だが、次の 2 つは **すでに作らない／やめると決めたものを、指示書が
作れと言っている**種類である。指示書どおりに実装すると退行する。

- **イベントマーカー（時間軸上の時刻ブックマーク）— U20 / U21**
  U21 は目的・受け入れ基準を含む全体が「イベントマーカーの表示・追加・編集・削除 UI を提供する」ことで
  組み立てられているが、これは **2026-06-21 に要件から外し、UI からも撤去した非目標**である
  （`docs/要件定義書.md` FR-66 および第 7.4 節）。U21 のうち生きているのは時間軸 UI 本体だけで、
  イベントマーカーに関する記述は**すべて無効**。
- **穴 / 飛び地の追加が 1 クリック導線 — U25**
  U25 は「ツール起動後の最初のクリック位置が対象面の内外かで穴／飛び地を自動判定する」と書いているが、
  この設計は 2026-08-06 に**否定して 2 段階の導線へ統一済み**（1 クリック目 = 対象面の選択、2 クリック目 = 実行）。
  実装 `src/ui/ring-edit/useRingEditTool.ts` は phase 1 = TARGET / phase 2 = ACT として、旧設計を名指しで
  否定するコメントを持つ。U25 が書いているのは、まさにその否定された旧設計である。
