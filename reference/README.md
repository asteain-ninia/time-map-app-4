# reference/ — 前世代（v3）の参照素材（凍結）

このディレクトリは、本プロダクト（v4）を作るにあたって参照した**前世代の資料**である。
**現行の正は `docs/` とソースコードにあり、ここではない。**

`v3-docs/` の文書は表題も見出し構成も現行の `docs/` とよく似ているため、ディレクトリ名だけが
見分けの手がかりになる。開いた文書がどちらか分からなくなったら、パスを確かめること。

## 中身

| パス | 内容 |
| --- | --- |
| `v3-docs/要件定義書.md` | 前世代の要件定義書 |
| `v3-docs/開発ガイド.md` | 前世代の開発ガイド |
| `data/base-map.svg` | 前世代のベースマップ素材 |

## 扱い

- **書き換えない。** 旧世代の記録としては正しく、書き換えると資料としての価値が失われる。
- 現行の仕様・方針の根拠として引用しない（開発ガイド §3.1 クリーンルーム原則）。
  必要な制約は v4 自身の要件・方針として `docs/` に直接書く。
- v3 の記述と現行が一致している箇所もある（例: `v3-docs/要件定義書.md` の「ファイル拡張子は
  `.gimoza` とする」は現行方針と同じ。**gimoza は前世代から継承した正名**であり、`tmap` のほうが
  v4 の開発時コードネームだった）。一致していても、根拠として引くのは `docs/` 側とする。
