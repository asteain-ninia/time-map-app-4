## 設計メモ（結線済み・参照用）

- **U07 リング階層の幾何検証とシーム（経度±180°）整合（技術方針 R3）**: U07
  `ring-hierarchy.ts` の `resolveRing` は、幾何述語（pointInPolygon /
  segmentsIntersect、U06）が「連続座標系で動作し、シーム展開は呼び出し側責務」
  と明記している（`geometry/predicates.ts` 冒頭）ため、量子化の前に U05 の
  `unwrapRing`（`geo/seam.ts`、barrel `domain/index.ts` で公開）へ委譲して
  リングを連続経度へ展開する。独自の折り返しは実装しない（単一の真実源）。
  ただし `unwrapRing` は各リングを自身の先頭頂点へアンカーする「リング単位」展開
  のため、シームを跨ぐ親-穴／兄弟／飛び地で頂点配列の開始側が互いに反対側だと
  両者が約 360° ずれる潜在不具合があった。比較直前に U05 `worldWrapReplicas`
  （turns -2..+2）で他方を基準リングのワールドターンへ整合させる `alignRingTo`／
  `resolveAlignedPair` を追加し、包含（`validateGeometry`）・兄弟/飛び地非重複
  （`checkGroupPairsNonOverlap`）の全 cross-ring 判定をペア整合後に実行する。
  ±360° ロジックは U05 を再利用（単一真実源を維持、U07 で再発明しない）。
  回帰テストは `ring-hierarchy.test.ts`「seam-crossing rings (U05 unwrap)」と
  「seam-crossing pairs with MISMATCHED anchors」（包含・飛び地重複・兄弟非重複の
  各経路で開始側を反対側に並べたケース）に追加済み。
- **U07 穴削除時の飛び地の扱い（FR-24 / FR-25 整合）**: 穴を削除すると穴の空白が
  親領土の実体に吸収されるため、穴内部の飛び地（領土）は親領土の実体に内包され
  独立外周にできない（旧実装の「飛び地をトップレベルへ繰り上げ」は自ユニットの
  `validateGeometry` が enclaves-overlap と判定する欠陥だった）。現在は飛び地を
  吸収して削除し、その子（穴）を穴の親領土へ繰り上げる（領土削除の鏡像）。再編後
  は構造（交互）と幾何（FR-25）の双方が緑であることを単体テストで保証する。
