## 2. 既知の不具合・制限（機能欠陥ではないと判断したもの）

- **L1: 経度±180度の継ぎ目に関するコーナーケースの繰越**。`.autopilot/SEAM-AUDIT.md §5` の C5 / C11 / C12 / C13 / C14（M10 部分）/ C15。いずれも 360度を超える幅・複数周回・極端なパン量・契約違反の座標といった通常の編集では到達しない入力か、防御層の強化・UI 仕様の合意を要する項目。重大な根本原因は解決済み。
- **L2: 海岸線のように頂点が密な地物を大量選択したまま動かすと 1 フレーム 27ms 程度かかる**（描画予算 16.6ms 超過）。複数頂点の同時移動における集合デルタ拘束の計算量による。拘束の意味論を壊さずに速くする方法が未検討。
- **L3: 外部レビューで指摘され、不実装と決めたもの**。展開処理の CPU 有界性、1GiB 境界の扱い、自己解凍形式の ZIP。いずれも敵対的に細工されたファイルでしか到達せず、ローカル単一利用者のオフラインツールには不相応な堅牢化と判断した。
