## 2. やったこと

### 中身 1 — 重なり解決（V13 / N-17・N-18）

- **呼び名（N-18）**: 名前が空の面を内部 ID（`f-5-4`）で呼ばず、「名前のない面（1200年に作成）」と

  探す）。規則は `src/ui/conflict/participant-name.ts`、使うのは確定の束ね（`consistency-binding.ts`

- **色見本（N-17・V13 ③）**: 行とラジオに **地図で塗られている色** の色見本（`participant-color.ts`。
  試しの状態の、重なりの年の姿から読む）。凡例の各行にミニマップと同じ色の色見本、**選ぶ前だけ**
  灰色の行（「残す側を選ぶ前の面」）も出す。
- **冒頭の言い換え**: 冒頭の文は変えず、すぐ下に「末端地物は『国境を持つ面』のことです。…」を
  添えた（用語集 §H.1 の説明文）。
- **状態行（V13 ⑦）**: 適用すると「アルラーク国とバアカの重なりを解消しました（1200年）」。
  年は止まっていた編集の錨の年。2 件以上は「AとBほか n 件」。［キャンセル］では「重なりの解決を
  やめました。止まっていた編集は記録していません。」（中立の色）。`App.tsx` は行を足すだけ。
- **見つけて直した不具合**: 7 手の E2E を書いて走らせると、**適用した直後に「描きかけを捨てますか」
  の板が出て、地図も道具も押せなくなった**。追加の道具が、重なりで止まっている下書き（保存を
  押した 4 頂点）を打ちかけと数えていたのが根で、宿主が適用後に追加した面へ選択を移した瞬間に
  「選択が変わった」見張りが反応していた。道具の構え直しでは「描きかけの頂点 4 個を捨てました」と

### 中身 2 — 背景地図の縦横比（G-10）

- 差し替えの手続き（`file-ops/basemap-replace.ts` の `runBasemapReplace`）に、縦横比を聞く口
  （`confirmAspect`）と補正の口（`correctImage`）を足した。判定は `decideBasemapReplacement` の 1 本。
- 板（`file-ops/BasemapAspectDialog.tsx`）: 「この画像は 3:2 です。2:1 に補正しますか、このまま
  使いますか。」と説明 1 行、［2:1 に補正する］［このまま使う］［やめる］。2:1 から 4 倍を超えて

- 結末を状態行に出す（補正した／比のまま使った／やめた）。

### 中身 3 — 残りの未結線

- **G-12**: 強調（赤道・0 度・180 度の太い赤線）は **前から描かれていた**（`render/grid-layer.ts` が
  `latitudeEmphasis` / `longitudeEmphasis` を呼ぶ）。調査 08 が「未結線」としたのは便利関数

  同じ **セッション限りの見え方**（`SessionState.gridEmphasisVisible`。保存しない・未保存の印を
  立てない・読むだけでも押せる）。`GridStyle.emphasizeSpecialLines` で線・ラベル・縁取りを切り替え、
  再描画の見張りに足した。
- **G-14**: **先に実機（E2E の探針）で確かめた**。結果は §10。外周の外へは出なかったが、
  **隣の穴の中へ入れる形は通っていた** ので直した。編集の束ね（`createLiveEditBinding`）の
  `checkConstraints` が空を返していたのが根で、ここに `ring-hierarchy-gate.ts` の関門を入れた ――
  参照が変わった錨に載る、環を 2 つ以上持つ面を U07 に掛け、**この編集で新しく壊したときだけ**
  断る（前から壊れていた古いデータの面は止めない）。断ったとき、編集ドラッグの経路はこれまで
  **黙って元へ戻るだけ** だったので、理由を状態行へ出す口を足した（`hit-test.ts` →
  `App.announceEditRejectionRef`）。
- **G-15**: 「見た目」の欄で自動配色を外した瞬間、色と透過を **地物にいま塗られている色** から取る
  （`property/auto-color-off.ts` が `manualColorsOnDisable` を呼ぶ。呼ぶのは `BasicInfoForm.tsx`。
  `PropertyPanel.tsx` は触っていない）。
- **G-21**: 上下限に着いたまま［＋］［−］・Ctrl+= / Ctrl+-・メニューを押すと、ズームボタンの脇に
  「拡大の上限（50倍）です」、状態行に「これ以上は拡大できません。…上限は設定の「最大ズーム倍率」で
  変えられます。」。判定は `map/zoom-limit-notice.ts`（いまの上下限の値を読むだけ）。ズームの処理は
  書き換えず、地図の結線（`mount/render.ts` の `zoomMapRef`）に **押す前の知らせ口を 1 つ** 足した。
  脇の文（`ZoomLimitNote.tsx`）は押せず、倍率が動いたら消える。

### 中身 5 — 結合点 #12 の回帰テスト

「削除／年を動かしてその年に存在しなくする／開き直す」の 3 つでパネルが消えることを E2E に
した。**探針では 3 つのうち 2 つが消えていなかった**:

- **年の移動**: パネルは描くときにいまの年の姿を引くが、宿主は時刻の変化では描き直さないので
  **1 つ遅れて** 消えていた（1000 年へ動かしても残り、1300 年へ戻すと消えた）。パネルが現在時刻を
  購読して、その場で描き直す形にした（`DetailPanels.tsx` の `liveStore`）。在る年へ戻れば、閉じて
  いないパネルはまた見える。
- **開き直し**: 掃除は「その id がドメインに在るか」で見ていたので、**同じファイルを開き直すと
  id が同じまま残った**。読み込み・新規で動く印（`projectLoadNonce`）で全部閉じる（教訓 §5.90）。

## 4. 実装者がその場で決めたもの（README の B-3 へ戻し方つきで載せた）

## 5. 所有者の裁定が要るもの

- **G-12 の読み方**: 「強調表示」を FR-13 の 3 本（赤道・0 度・180 度）の強調と読み、その
  **切り替え** を置いた。現状分析 §6.2 の一覧は「10 度ごとを太線にできる」と書いていたが、
  FR-13 の条文の強調は 3 本の線のことなので採らなかった。**「10 度ごと（主線）を太くする」が
  欲しかったのなら、別の機能として足す**（`GridStyle` に主線の間隔を足す形になる）。
- **縦横比の補正のしかた**: 余白を足す（画像はそのまま・地図の端に空きができる）か、引き伸ばす
  （地図いっぱい・歪む＝「このまま使う」と同じ）か。いまは前者。
- ~~**年を動かして無くなった地物の詳細パネル**: 見えなくする（いま）か、閉じるか。~~ → 司令塔が「閉じる」に決めた（2026-09-07 の一覧のチェックの裁定と揃える。§12）。
- **縦横比の補正のしかた**（上の 2 つ目）の材料: 補正すると絵が地図の中で縮み、端の地物と合わなくなる（反証 2-4）。板はそれを言うようにした（§12）。

## 7. 新しい教訓（開発ガイド §5 へ入れたもの）

- **§5.89 確定の手続きに渡した下書きを、まだ「打ちかけ」と数えない** ―― 重なり解決の適用直後に
  「捨てますか」が出て操作できなくなった件。見張りが反応してよいのは利用者自身の遷移だけ。
- **§5.90 「消えたか」を id の有無で見る掃除は、同じ id のまま入れ替わったものを見逃す** ――
  詳細パネルが同じファイルの開き直しで残った件。入れ替わりは世代の印で見る。

G-14（確定前の検査が空だった）は既存の §5.26 で説明できるので、新しい教訓にはしていない。
年の移動で詳細パネルが 1 つ遅れて消えた件は §5.35（全依存先へ通知する）で説明できる。

### 12.2 実装者がその場で決めたもの（README の B-3 へ戻し方つきで載せた）

1. **違反の見分けの鍵**: 種類・環・相手の環。穴どうしの重なり・飛び地どうしの重なりは対称なので

5. **ホイールの回転のまとまり**: 前のノッチから 400 ミリ秒以内。動いたノッチもまとまりを続ける。
