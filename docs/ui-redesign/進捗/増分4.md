## 2. やったこと（実装計画 §4 の中身 1〜10）

### 1. 排他タブを廃し、右パネルを上下 2 区画の同時表示に

`src/ui/shell/Sidebar.tsx` を作り替えた。**FR-111 の「2 区画」という数は守り、変えたのは
「同時に見えるか」だけ**である。

- 見出しのボタン（`sidebar-tab-list` / `sidebar-tab-properties`）は **役割で維持**した（T-1）。
  役割は「その区画へ寄せる」に変わったので `role="tab"` / `aria-selected` はやめ、
  トグルの `aria-pressed` にした。22 本の E2E がこの 2 つを押して区画を出しているので、
  押したら寄せる形にしておけば意図も検査も生きたまま残る。
- **結合点 #3 を潰した。** 右クリックの「プロパティを編集」が
  `document.getElementById('sidebar-tab-properties')?.click()` に文字列で依存していたのを、
  `SidebarFocusStore`（どの区画に注目させるかの口）へ置き換えた。呼び出し元は 2 か所
  （右クリックと追加の確定）だけである。
- **仕切りを掴んで上下に動かせる**（`sidebar-splitter`）。既定は上 60%。設計書 §B.1 の
  「470/312」と §B.2 の「350/232」はどちらも 60:40 なので、px ではなく割合で持つ。
- 右パネルの幅を **220 → 280px** にした（設計書 §B.2）。220px では素性欄の内容幅 243px が
  収まらず常時横スクロールが出ていた（現状分析 §0-2）。

### 2〜3b. 台帳を階層ツリー＋仮想スクロールに、行に 6 つの中身と重複名の 3 段

`src/ui/discovery/ledger.ts`（純関数）＋ `FeatureLedger.tsx`（器）＋ `ledger-source.ts`（材料）。

- **行 28px 固定・折り返しなし。** 現状は 31.6／49.2／51.6px の 3 種類で 113 行（14.6%）が
  2 行になっていた。高さが揃っていないと仮想スクロールの計算が成り立たない。
- 親子は **ドメインの 1 本**（`buildForest`）から引く（G-7）。行は
  `[色][展開][名前][種別][錨の本数][👁]`。
- **重複名の見分けは 3 段**（〈親名〉→ 階層のみち → 通し番号と座標）で、**かたまりごとに
  独立に段を上げる**。実データの「???州」10 件は全部デーレ共和国の子なので、〈親名〉でも
  階層のみちでも区別できず、座標まで出る（E2E で 10 件が全部ちがう見分けを持つことを固定）。
- 代表点は **重複名のものだけ**計算する（775 件ぶん計算すると毎回 5 万頂点を走る）。
- **絞り込み中に自分で開いた親は、当たらない子も出す**（「押しても何も起きない三角」を
  作らない＝C9 の②）。絞り込みのために自動で開いた親は当たった子だけを出す。

### 4. 作業のまとまり（束）と「◀前へ 3/220 次へ▶」

`src/ui/discovery/bundle.ts`（純関数）＋ `store.ledger`（3 つの部品が同じ状態を読み書きする）。

- **既定の式 10 種**を用意し、**式そのものを画面に出して編集できる**（実データの命名規約を
  アプリは知らないため）。
- **「済」は保存せず導出する**（作った時点の名前・種別と、いまの名前・種別が違うか）。
  保存形式には何も足していない（K-9）。
- **開き直しても続けられる仕掛け**: 式は **通史で当てはめる**（過去または現在のどこかの錨で
  当てはまった地物がメンバー。基準は当てはまった**いちばん古い**姿）。だから改名して式から
  外れた地物も束から落ちず、同じ式を選び直せば同じ件数が同じ並びで出て、直したものが済に
  なる。**ただし錨の開始年ちょうどで直したときは上書きになって過去の名前が残らない**ので
  この限りではない（`docs/現状.md` B51）。
- **束を作った瞬間に、先頭の未処理を選び、カメラを合わせ、名前欄に焦点**（E2E で固定）。
- **Ctrl+Z は改名だけを戻し、カーソルは戻った地物へ移る。** 追いかけ方は「済が外れた地物を
  見る」――どのコマンドが取り消されたかを聞かなくても結果状態から分かる（教訓 5.6）。

### 5. その場編集と、素性欄の Enter＝「保存して次へ」

- 一覧の名前・種別をダブルクリック（または選んで F2）でその場で直せる。
- 素性欄の名前欄・種別欄の **Enter が「保存して次へ」**、**Ctrl+Enter は保存だけ**（§I.2）。
- **保存の行き先は素性欄とまったく同じ 1 本**（`decideEditPlan` → `buildEditIntent` →
  `editDispatch`）を通る。断られたら理由を返して共通枠へ出す。

### 6. 母集団は 2 つのまま／絞り込みと検索を 1 つに

- 母集団は「現在時刻／通史」の 2 択のまま（U-18 / §N-14 の (A)）。「この年に変わったもの」は
  **束の既定の式**の 1 つ。
- **「地物を検索」（Ctrl+F）は一覧の絞り込み欄へ焦点を入れるだけ**になった（E-6）。検索
  モーダルは削除した。母集団が 2 つある状態（N-41）と、年を属性の検索対象に入れて数字 1 文字で
  ほぼ全件が一致する罠（C10）が同時に消える。

### 6b. どこへでも移動（Ctrl+P）

`src/ui/discovery/jump-palette.ts` に **5 規則**を固定した（設計書 §C.2 の 26）。
①数字だけなら年の候補だけ ②文字を含むなら地物名だけ（前方一致 → 部分一致。属性値・年・
詳細文書は対象にしない）③同名は台帳と同じ 3 段 ④コマンドは `>` のときだけ ⑤12 件で打ち切り。
**「1」と打つと年の候補だけが出る**ことを実アプリの E2E で固定した。

### 7. 表示制御をオプションバーの「表示 ▾」へ

- `offsetTop` 28,546px（63 画面ぶん下）→ **1 クリック**（C7）。
- **種別（FR-40 の札）ごとに 1 行 × ［隠す］［薄くする］［目立たせる］**（V5(b)）。
  薄くするは不透明度 0.25 固定・確定不要・もう一度押すと解除・取り消しの対象外。
  **点/線/面 の軸とは別物**で、実データ 775 件は全件に札が入っているので V5 はこちらでしか
  成り立たない。
- **深さの強調**（G-6 / 現状.md R8）を結線した。`setEmphasizedDepth` はドメインに在るのに
  呼び出し元が 1 つも無かった。
- 道具に属さない部品なので、オプションバーへ**常設で**差し込む口
  （`registerPersistentSlot`）を足した。道具の枠へ入れると、道具が帯を持ち直した瞬間に落ちる。

### 8. 素性欄（スクロール位置・親欄 2 行・長さ）

- **地物を替えたらスクロール位置を先頭へ戻す**（C5 の④）。DOM を名前で探さず、自分の祖先から
  実際にスクロールしている器を見つけて戻す。
- **上位領域（親）の欄を 2 行で置いた**（値の行とボタンの行）。3 ボタンは **増分 7 まで無効**で、
  押せない理由を**画面に**出す（ツールチップだけにしない）。現状.md B27 の半分が解消。
- **線の長さ（km）**を面積と同じ形の行として置いた（G-1 / FR-19 must ＝ 現状.md R1）。
  **線のときだけ解く** ―― 面や点でも解くと `featuresAt` の走査が 1 回増え、面積側の
  「1 回だけ」の約束が崩れる。

### 9. 選択が必ず地図に見える

`src/ui/map/always-drawn.ts` ＋ `committed-features.ts`。

- **規則 1**: 選択中の地物と親までの道筋は表示条件に関わらず必ず描く。FR-42 が畳んで
  `resolved.shapes` に入っていない地物は、その場で自分の形を解いて足す（幾何の作り方は
  ドメインの `resolveDisplayShapes` をそのまま使う）。
- **規則 3**: 必ず描くものは **重ね順を保ったまま描画列の最後へ**まとめて重ねる。道筋の
  中どうしの前後関係は導出どおりなので、FR-113 の導出規則は変えていない。
- **規則 2（深さを自動で上げる）は採らなかった。** §5 に理由を書いた。**状態行の文は出す。**

### 11.3 足した検査

- **A1**: 「どの窓の大きさでも、一覧の行が区画の中に見えている（起動直後 / 1280×800 / 800×600 / 1366×768）」。
  **矩形の交差で数える**（`toBeVisible` は先祖のスクロール外も真にする＝教訓 5.62）。下限を元に戻すと赤くなることを確かめた。
- **A2**: 「器をいちばん低くしても、名前欄が保存列の下に潜らない」。
- **A1 の副作用（§11.7）**: 素性欄の節を開く E2E ヘルパを **「前面に出るまで動かして押す」**
  形にし、どのスクロール位置でも出てこないときは **器・見出し・保存列・空き帯の実測値を
  添えて落とす**（`force` では押さない ―― この罠そのものを通してしまうため）。
- **A3**: 5,000 行の下端まで送って `syn-4999` が見え、行の実高が 28px であること。
- **B2**: 「V3 の 3 手: Ctrl+P で選ぶと、一覧に行が出て素性欄にも出る」。
- **B7**: 「隠れていても、**選んでいるあいだは本体を掴める**」／「選んでいるのが別の地物なら
  掴めないまま」（単体。当たり判定）。**本番だけ直して検査を置いていなかった**ので足した
  （開発ガイド §1.9）。必ず描く集合に渡す選択を潰すと前者だけが赤くなることを確かめた。
- **B8**: 「一覧を鍵盤で操れる（矢印・Home/End・Enter・F2）」。**窓の外の行にも届く**ことを End で見る。
- **B11 / K-6**: 「読むだけでその場編集を試すと、理由と『鍵を直せるにする』ボタンが出る」。押すと鍵が開き、今度は入力欄が開く（空振りしていない証）。
- **C1〜C3**: 「どこへでも移動: 地物名で飛べる / `>` でコマンドが出る / 外を押すと閉じる」。**地物がある状態で**見る（空のプロジェクトでは「0 件」と「不具合」の区別が付かない）。
- **C4**: `99999999999999999999` と `1000001` を候補にしない（`1000000` は候補になる）。
- **メニュー「一覧で絞り込む」（F4）**: 焦点が入るだけでなく、**そのまま打つと件数が
  12件 → 1 / 12件 に変わる**。**DOM の行数では数えない**（仮想スクロールなので窓の中の
  行しか無い＝教訓 5.62 と同じ型）。
- **D1**: 「0 年で直したまとまりが、保存して開き直しても済ごと戻る」。**アプリを終了して立ち上げ直す**。保存側の畳み込みを外すと赤くなることを確かめた。
- **K-2**: 「表示 ▾ は開いていても閉じていても、地図の当たりを黙って奪わない」（5×5 の格子を開・閉の両方で走査）。
- **K-3**: 「地物を選んでも、右パネルの 2 区画の矩形が動かない」。
- **旧 BUG#3 の後継**: 「隠した地物を一覧から選んでも、地図には出る」（＋「表示 ▾」に緩める導線が出る）。
- **旧 BUG#9 の後継**: 「年を動かすと、その年に居ない地物の行は一覧から消える」（単体）。
- **探索 spec の下限**: 掃いた件数・カメラが動いた回数・「済」を確かめられた件数を数え、**1 回も起きなかったら異常**として記録する（異常だけを数える形だと、何も起きなくても緑になる）。
- **束の往復**: 保存の形と行き来しても並び・基準・カーソル・作成日時が変わらない／知らない種類は式として読む／範囲の外のカーソルは収める。manifest の JSON 往復と「節が無ければ書かない」も固定。
