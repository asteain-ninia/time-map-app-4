## 2. やったこと（実装計画 8C の中身 1〜5）

### 1 `removeSurveyLine(state, id)`（純関数）

`src/domain/survey/survey-state.ts`。確定した線を 1 件だけ消す。1 回の測量は正距円筒の線と
大円の線の 2 本を **同じ `SurveyLine`（同じ id）から**描いているので、1 件消せば 2 本が
一緒に消える。途中の始点と id の発行（`nextLineId`）はそのまま。無い id は同じ参照を返す。
ストアには `surveyRemoveLine(lineId)` を足した（ほかの測量の操作と同じく、変わらなければ
書かない）。線は保存しない表示なので、取り消しの記録にも未保存の印にも触らない
（［測量結果をクリア］と同じ扱い）。

### 2 2 本の曲線の当たり判定

`src/domain/survey/survey-hit-test.ts` の `surveyLinesAt(lines, point, pxPerDegree)`。

- 正距円筒の線と大円の線の **どちらに当たっても同じ測量の id** を返す（1 件として数える）。
- 判定は **画面上 8px**（`SURVEY_LINE_HIT_TOLERANCE_PX`）。正距円筒の画面変換は経度・緯度とも
  1 度 = `zoom` px の等方な一次変換なので、許容値を `8 / zoom` 度に直して世界座標の上で
  測る。描画層を引かずに純粋なドメインのまま、画面の 8px と同じ判定になる。
- 結果は **近い順**（同じ近さなら古い順）。どれか 1 つに絞らない。

地図の右クリックの口（`ui/map/live-context-menu-port.ts`）に省略できる依存
`probeSurveyLines` を足し、合成ルート（`ui/map/mount/hit-test.ts`）が上の関数を渡す。
当たった線の id は要求（`ContextMenuRequest.surveyLineIds`）に載る。**地図から来た要求だけ**が
これを持つので、一覧の行の右クリックで開いたメニューには出ない。

### 3 候補が複数のとき

右クリックメニューの器（`ui/map/MapContextMenu.tsx`）に **省略できる props を 2 つ**
（`surveyItemsFor` / `onRemoveSurveyLine`）足した。器の型・関数の引数（`ContextMenuModel` /
`dispatchMenuItem` / `launchMenuItem` / `OnSelectMenuItem`）は変えていない。

- 項目は開いた瞬間に凍結し、**メニューの先頭**に並べる。
- 当たった線が 1 本なら **「この線を消す」**、2 本以上なら測量ごとに 1 項目ずつ
  **「1,234km の線を消す」**（大円の距離・整数の km。`ui/survey/survey-menu.ts`）。
- 押すとストアの `surveyRemoveLine` を呼ぶだけ。

### 4 世界の東西端をまたぐ線

線の経度は連続値で持っている（+179° から −179° へ測った線は 179°〜181° に描かれ、地図の
左端にはその複製 −181°〜−179° が見えている）。当たり判定は押した点の経度に 360° の整数倍を
足し引きし、線の経度の範囲に重なる複製ごとに測る。単体（`survey-hit-test.test.ts`）と
E2E（左端の複製の上を右クリックして消す）の両方で固定した。

### 5 凡例・度分秒・「測っている間は地物を選べません」

- **凡例（N-52）**: 大円の線を **破線**（`[6, 4]`）にし、正距円筒の線は実線のまま。
  オプションバーの距離のラベル「正距円筒」「大円」の **下に、地図の線と同じ色・太さ・線種の
  線**を引いた（`.survey-controls__legend`）。指を載せると「地図の上のまっすぐな線（実線）」
  「地球の上の最短の道すじ（破線）」が出る。最初は距離の前に SVG の見本を並べたが、1280px で
  読み取りごと「≫」へ畳まれた（§1 の §5.69 の行）。下線なら幅は 1px も増えない。
- **度分秒（G-11）**: **増分 5a で済んでいた**（「座標 ▾」の［両方／度分秒／十進］）。
  V15 の E2E に「度分秒で読める」を 1 行足して固定しただけである。
- **「測っている間は地物を選べません」（N-54）**: 次の一手を「地図で 2 点を押すと距離が
  出ます。測っている間は地物を選べません。」にした（設計書 §C.4 の測るの行）。次の一手の欄は
  縮む役なので **1280px では文が「…」で切れる**（前半もすでに切れていた）。全文を `title` にも
  持たせ、指を載せれば読めるようにした（`ui/shell/OptionBar.tsx`）。

### 完了の定義の「`U`」

V15 の 1 手目は打鍵 `U`（設計書 §I.2）だが、**道具の単一キーは `Shift+F` 以外どれも
入っていなかった**（増分 5 の申し送り）。完了の定義を満たすため、コマンド `tools.survey` を
足して ツールのメニューに `U` で載せた（`ui/shell/commands.ts` / `menu.ts`）。中身はレールの
「📏 測る」と同じ切り替えで、読むだけでも効く。

**始点を置いた途中（下書き中）は `U` が効かない。** 下書きのあいだは大域の打鍵が止まる
（`SurveyToolController` の `onDrawingChange` → `shortcutsSuspended`）という既存の規則に
従っている。途中で終えたいときは、まず `Esc` で始点を捨ててから `U` を押す（または
［測量を終える］を押す）。手で V15 を試すと当たるので書いておく。

## 4. 実装者がその場で決めたもの（配下 README の B-3 へ載せた）

1. **測量の線に当たった右クリックは、下の地物を選択へ引き上げない。** 線は地物より上に
   描かれていて、押した相手は線だからである。引き上げると、線を消すつもりの右クリックが
   下の国を選んでしまう。メニューの地物の項目は、空の場所を右クリックしたときと同じく
   **いまの選択**に対して出る。
2. **項目の言い方**: 1 本なら「この線を消す」、2 本以上なら「1,234km の線を消す」で、
   距離は **大円**（FR-15 が必ず描く線。読み取りの「大円」と同じ数）、**整数の km**。
3. **「この線を消す」はメニューの先頭**（道具の確定・やめるより前）。押した相手そのものへの
   操作だからである。
4. **読むだけでも、測るを終えたあとでも消せる。** 線は測るを終えても描かれている（FR-15）ので、
   描かれている線は消せる。
5. **線を消すことは取り消し（Ctrl+Z）の対象にしない。** ［測量結果をクリア］と同じく、
   保存しない表示の操作である。
6. **凡例はラベルの下線**（§3 の 3・4 行目）。
7. **次の一手の全文を `title` にも持たせた**（§2 の 5）。
8. **`U` は大域の打鍵**（§3 の 5 行目）。

## 5. 所有者の裁定が要るもの

- **測っている間も、線から外れた右クリックは地物を選択へ引き上げる**（`docs/現状.md` の
  **B65**。実データの探索で確かめた）。次の一手は「測っている間は地物を選べません」と言うが、
  これは **左クリック**の話で、右クリックは測る前から「押した地物がコマンドの相手になる」
  （教訓 5.11）。①測っている間は右クリックでも引き上げない ②このまま、のどちらにするか。
  ①にすると、測っている間の右クリックは地物の項目を **いまの選択**に対して出すことになる。
- **同じ距離に丸まる 2 本の線は、項目が同じ文になる**（例: 同じ 2 点を 2 回測った）。
  どちらを消しても見た目は同じなので実害は小さいが、言い分けたいなら始点の座標を添える等の
  形がある。
- **道具の単一キーは `Shift+F` と `U` だけ**（設計書 §I.2 の残り `V` / `N` / `L` / `P` /
  `R` / `K` / `D` / `H` / `J` は未着手。増分 5 の申し送りから変わっていない）。どの増分で
  入れるか。
