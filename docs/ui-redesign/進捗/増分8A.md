## 2. やったこと（実装計画 §8 の 8A の中身 1〜4）

### 1 掴み半径を画面倍率に連動させる（下限 8px）

`src/ui/map/grab-radius.ts`。倍率は「世界全体表示（360°×180° がちょうど収まる倍率）の何倍か」で測り、
**16 倍までは 8px、そこから倍率に比例して広げ、32 倍で 16px に止める**（**手直しで 64 倍まで 8px・128 倍で
16px に改めた**。既定のズーム範囲では 8px のまま。§12）。当たり判定（`mount/hit-test.ts` の
`hitTester`）と候補一覧の探針（`probeNear`）の両方に同じ値を渡す。`live-hit-test.ts` は 1 行も触っていない
（もともと `radiusPx` を受け取れる形だった）。

**効き目は小さい**ことを正直に書いておく。既定のズーム上限は 50px/度で、900px 幅の地図なら世界全体表示は
およそ 2.5px/度なので、届く倍率は 20 倍前後である。既定の設定では半径はほぼ 8〜10px の範囲でしか動かない。
実データの密度（全体表示で隣まで 0.4px 台）への答えは半径ではなく **候補一覧** である（設計書 §E.1 V9 の
「実データ密度では候補一覧が既定、拡大は補助」）。

### 2 候補が 2 つ以上のときは、クリック位置の脇に一覧を出す（台帳 #12）

器は増分 6 にあった（`VertexCandidateList` / `VertexCandidateStore`）。中身と当たり判定を入れた。

- **1 行の書式**: 「頂点 #412（34.10°N 12.51°E・アルラーク国と共有）」。番号は実データの頂点 id（`v412`）の数字。
  **主になる地物**はいま選んでいる地物がその頂点を引いていればそれ（選んだ瞬間に選択が隣の国へ替わらない）、
  引いていなければ当たり判定の持ち主で、そのときは名前を書く。共有の相手は 2 つまで名前、残りは「ほか N 件」。
- **共有の相手は引いている地物の全部から作る**（`vertexCitersFor`。現状.md B42 の後半）。
- 行は近い順に **20 行まで**。残りは「ほか N 件。拡大すると絞れます。」。全体表示のバアカでは数十が入る
  （**手直しで［もっと見る］を足し、21 件目より先も選べるようにした**。§12）。
- **出すのは動かさずに離したときだけ**（`createVertexCandidateGesture`）。押すたびにまず畳む。
- **一覧から選んだ頂点は、次にその近くを押したとき最寄りより優先して掴む**（`preferSelectedVertex`。
  **手直しで「一覧から選んだ直後の左ドラッグ 1 回だけ」に絞った**。§12）。
- 閉じ方は台帳 #5 と同じ `use-dismissable`（一覧の外の押下・Escape）。世界・年・道具・表示・カメラが
  替わったら畳む（`watchCandidateStaleness`）。
- 開閉を `onOpenChange` で報せ、App が `popoverOpenChange('vertex-candidates')` で **鍵盤の持ち主 `popover`**
  を名乗らせる。`role="dialog"`（非モーダル）にして、K-2 の走査が 1 枚として数えられるようにした。
- 一覧の大きさは 216×180 → **280×240px**（1 行に座標と共有の相手を書くため）。

### 3 ハンドルが出ないときに理由と［拡大］を出す（§H.5）

`src/ui/map/HandleCapNotice.tsx`（描画しない部品）と `src/ui/map/handle-cap.ts`。オプションバーの「次の一手」に
「頂点が 2,230 あり、上限 2,000 のため印を出していません。拡大すると出ます」と［拡大］を出す。

- 数えるのは `active-feature-handles.ts` に足した `activeFeatureHandleCapStatus`（描画の上限の判定と同じ入力・
  同じ順。読むだけの見込みだったファイルに関数を 1 つ足した＝§3）。
- 出す条件は印を描く条件と同じ（鍵が開いていて、選ぶ・頂点・動かすを構えている）。読むだけでは出さない。
- ［拡大］は **画面の真ん中にいちばん近い、その地物の頂点を動かない点にして**、印が出るまで 1 段（Ctrl+= と
  同じ倍率）ずつ寄せる（最大 30 段、ズームの上限で止まる）。視野の真ん中で寄せると地物が画面の外へ出て
  「視野内 0 個 ≤ 上限」で黙って止まりうるため。カメラの書き込みは最後に 1 回だけ。
- 上限が 0（印を出さない設定）のときは「拡大すると出ます」を言わず、［拡大］も出さない。
- 帯への押し込みは書いた人の印つき（`clearChromeIfMine`）、帯が持ち直されたら押し直す（`useOptionBarEpoch`）。

### 4 矩形選択の枠を描く（N-07）／辺の中点のクリックでも頂点が増える（N-06）

- **矩形の枠**: `src/ui/map/rubber-band.ts`。選択の口を包み（`withRubberBand`）、空いた所の押下から始まった
  ドラッグがしきい値を越えたら、編集ハンドルの層のいちばん上に **破線の縁と薄い塗り**を足す
  （`withRubberBandLayer`。`mount/render.ts` は getter を包む 2 行だけ）。枠は経緯度の矩形で、U22 の矩形選択が
  判定に使う矩形そのものである。canvas に描くので K-2 の台帳の対象外。
- **辺の中点のクリック**: `src/ui/map/edge-click.ts` と `edit-session-adapter.ts` の `edgeClickPoint`。中点の印を
  押して動かさずに離したら、**その辺のちょうど中点**（描いている印と同じ `computeHandles` の `midpoint`。
  経度 180° をまたぐ辺でも同じ所）に頂点を 1 つ足し、ドラッグと同じ `confirmRelease` で確定する（取り消し 1 単位）。

## 4. 実装者がその場で決めたもの（README の B-3 へ載せた）

1. **掴める距離の曲線**: 16 倍まで 8px、32 倍で 16px、その間は比例。**戻し方**: `grabRadiusPx` が常に `GRAB_RADIUS_MIN_PX` を返すようにする。
   → **手直しで 64 倍まで 8px・128 倍で 16px に改めた**（§12.3 の 1）。
2. **候補一覧はクリックのときだけ出す**（§3 の 1 行目）。**戻し方**: `createVertexCandidateGesture` の `release` で `dragged` を見ずに出す（押した瞬間に出すなら `press` で `store.set`）。
3. ~~**一覧から選んだ頂点は、掴める距離の中なら最寄りより優先して掴む**。**戻し方**: `mount/hit-test.ts` の `preferSelectedVertex(...)` の包みを外す。~~
   → **手直しで「一覧から選んだ直後の左ドラッグ 1 回だけ」に絞った**（`preferSelectedVertex` は無くなり `preferListPick` になった。戻し方は §12.3 の 2）。
4. **行は 20 行まで**、残りは件数で出す。**戻し方**: `VERTEX_CANDIDATE_MAX_ROWS` を大きくする。
   → **手直しで［もっと見る］を足した**（§12.3 の 3）。
5. **［拡大］は印が出るまで段を重ね、地物の頂点を動かない点にする**。**戻し方**: `HandleCapNotice` の `zoomUntilShown` を `registry.dispatch(COMMAND_ID.ViewZoomIn)` 1 回に替える。

### 15.7 教訓

- **同じ帯へ書く 2 つの部品は、片方の「片付け」がもう片方の文を消しうる**。書き手の印で守れるのは「自分が書いたあとに誰かが書いた」場合だけで、「誰かが自分のあとに書いて、すぐ自分の片付けをする」場合は守れない（2-1 はこちら）。出す条件の側で、ほかの持ち主が帯を使う場面を外す必要がある。
- **集合演算を通した形は、元の頂点を黙って減らす**。隣と共有している頂点が減ると T 字になるので、形を作る経路では「元の頂点がどこへ行ったか」を確かめる。
