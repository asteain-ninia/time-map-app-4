# P5 学習容易性と安全性最優先（初回ガイド・状態の可視化・取り消し）
執筆: Grok（外部モデル、読み取り専用実行）／保存と検査: Opus

対象: gimoza（Electron + React + Canvas 2D の歴史地図エディタ）。レンズ: 初見でも迷わず、間違えても戻れる。技法: エラー防止、認識 > 想起、オンボーディング、空状態。内部（ドメイン・ストア・`recordCommand`）は再利用し、画面の置き方と状態の見せ方を白紙から組み直す。ソース・ビルド・git は変更していない。

合格条件の第一級は「機能があるか」ではなく「画面のどのボタンから何クリックで届くか」（01-現状分析.md §2.0）。数値の比較基準は調査 `C-klm-task-analysis.md` §3 の KLM 表（P=1.10 / B=0.20 / K=0.28 / H=0.40 / M=1.35、クリック = P+B = 1.30、心の準備つきクリック = M+P+B = 2.65）。

## A. 設計思想と 3 論点への立場

**設計思想。** この案は「使える人のための密度」より「迷わないこと・壊れないこと・戻れること」を先に置く。gimoza の使いにくさの件数最多は「いま何が起きているかが分からない」（報告 A ヒューリスティック別 17 件、01 §3 集計注記／C6）であり、認知的ウォークスルーでは 52 手中 40 手が失敗、原因の最多は「見えない」13・「フィードバックが無い」9・「モードに阻まれる」5 である（報告 B）。したがって画面の一等地（メニュー行・作業バー・状態行）は、開いているファイル・未保存・見る年と直す年・選んでいる物・いまの道具・直前の結果・取り消し可否を**常時・消えない形で**出す。機能の入口は「探して想起する」のではなく、空のとき・選んでいないとき・道具を持ったときに次の一手が文字で書いてある状態にする（認識 > 想起）。危険な操作（消す・上書き保存・過去の節目を書き換える・最後の外周を消す）は、実行前に何が起きるかを日本語で見せ、確定後は必ず 1 回の Ctrl+Z で戻せる（FR-73 / FR-94、開発ガイド §5.11）。自動消滅するトーストは使わない（§7.4-3、開発ガイド §5.12、K-7）。成功の手応えは状態行の「直前の結果」とウィンドウタイトルの未保存印で満たす（01 §5.1 #2 #3「最優先で覆す」）。初回ガイドは、既に定石どおり動いている重なり解決の「この画面の使い方」（番号つき手順・画面上の実物の名指し・恒久 OFF、`src/ui/conflict/strings.ts:87-101`、FR-118）をアプリ全体へ横展開する（01 §9.3、定石 15）。

### A-1. 追加／編集モードの排他（FR-75）を残すか

**本案の立場（主案）: 「見る／直す」の書き込み錠 1 段 + 道具 1 段。追加と編集の排他は「同時に 2 つの道具を持たない」として満たす。FR-75 の条文（ツールバーのトグルで追加モードと編集モードを切替、各モードで関連ツール群が出る）とは読みが違う。所有者の裁定が要る（01 §5.4、D56）。**

根拠:

- 安全性: 表示専用で編集経路を一括無効化する契約（K-6、開発ガイド §5.13）は残す。読むつもりで国境を動かしてしまう事故を防ぐ錠は、QGIS の「編集セッション」と同じ種類の安全装置であり、P5 はこれを捨てない。
- 学習容易性: 現状の 3 モード × 11 道具は「押すと損をするボタン」を並べている（C9）。表示専用をもう一度押すと編集モードに着地する（`src/ui/shell/useShell.ts:40-63`、01 §1.5）。選択と頂点編集は押しても挙動が変わらず、押すと選択が消える（C5-3、`store.ts:1405-1414`）。5 つの手順道具は押した瞬間に Ctrl+Z・Delete・Escape・右クリックが全部止まる（`App.tsx:2780-2791`、報告 04 §3.5）。初見の人が最初に学ぶべきは「読むか書くか」であり、「追加モードと編集モードの違い」ではない。
- 定石 1 は must 要件と正面衝突する唯一の定石（01 §9.1、F §4）。黙って要件を捨てず、黙って従わず、裁定を取る（D56）。

主案での読み替え:

| 現状 | 本案 |
| --- | --- |
| 表示専用 ⇄ 追加 ⇄ 編集（3 ラジオもどき） | **見る**（読み取り専用の錠）／**直す**（書く） |
| 追加モードのときだけ点・線・面 | 直すの中の道具「点を置く」「線を引く」「面を囲む」 |
| 編集モードのときだけ 8 道具 | 直すの中の道具として常時並ぶ。同時に 1 つだけ押せる |
| 見るでは地図クリック不可（§7.4-4） | **見るでも地図クリックで選べる・読める。書けない**（§7.4-4 を覆す。別裁定） |

FR-75 の「一方を有効にすると他方が無効」は、道具の排他（面を囲みながら頂点を動かさない）として残る。ツールバーに関連道具が出ることは、直すの左レールに全道具がラベルつきで並ぶことで満たす。追加モードという**段**は無くなる。

**フォールバック（所有者が FR-75 条文どおりを選んだ場合）:** 3 ボタンを「見る／足す／直す」に改名する。見るでも地図クリックで選べる（§7.4-4 は別裁定）。切替で選択を捨てない（C5。K-5 の「一時状態」から選択を外す解釈、A-4 と D 節）。表示専用の再押下で編集に着地する挙動は廃止する（ラベルと結果の不一致は学習を破壊する）。足すと直すは排他（FR-75 遵守）。このフォールバックでも、錠の意味と道具の意味は作業バーに常時書く。

**どちらを採っても守るもの:** K-6（見るでは編集経路を一括無効）、U-9（モードボタンにツールチップを付けない）、T-4（`aria-pressed`）、T-1（`mode-view` / `mode-add` / `mode-edit` の testid は役割として残す。主案では `mode-add` を道具 `tool-add.area` 側へ役割を移す改修が要る）。

### A-2. 時間軸に既存の錨の印を描くか

**本案の立場: 描く。自分で置く時刻しおり（§7.4-1、D32）は戻さない。既にデータにある歴史の節目（錨）を軸の上に描く。これは保存形式に新概念を足さないので K-9 に触れない（01 §5.2）。ただしこの読み分けは調査側の解釈であり、所有者の裁定が要る。**

P5 が描く理由（学習・安全）:

- 認識 > 想起: 「何年に何が起きたか」を軸から読めないと、歴史を刻む道具として時間軸が機能しない（C8）。実データは全 689 錨が 0 年の 1 点に集中しており、これから刻む（01 §7.1）。印が無いと、刻んだ結果を確認する手段が無い（C2・C6・C8 が同時に効く）。
- エラー防止: 属性保存は「編集対象の錨の開始時刻」に効き、時間帯の現在時刻ではない（C8-4、`PropertyPanel.tsx:296`）。見る年と直す年がずれうることを、軸上の印と状態行の 2 系統で常時見せる。黙って 0 年を上書きする事故を、見える化で止める。
- 規模: 将来 5,000 地物 × 平均 10 錨 = 5 万点を全部描くと破綻する（01 §5.2）。本案は (i) 年ごとの密度（薄い縦棒）を常時、(ii) 選択中の地物とその親・子の節目だけを点で描く。しおり UI は出さない（E2E `ux-cluster.spec.ts:216-219` が「栞 UI が存在しないこと」を固定している契約は維持）。

### A-3. 削除の方針（01 §6.3）

**本案の立場: 参照があれば拒否し、理由を日本語で出す（`judgeDeletion` / G-16）。全時刻を掃いて参照を黙って掃除する現行実装は採らない。所有者の裁定が要る（FR-41 は両方の読みを許す、報告 08 §6-2）。**

P5 が拒否側を採る理由:

- エラー防止: 実データは集約 3・子 86。デーレ共和国を消す操作が 60 州の所属を黙って付け替えるなら、確認なしの副作用は学習も安全も壊す。
- 認識: 拒否理由 87 件はドメインが既に持っている（G-23、N-38）。枠を 1 つ作れば「この地物を参照している地物が n 件あります」が出る。
- 取り消し: 拒否は履歴を汚さない。通した場合も 1 回の Ctrl+Z で戻す（FR-73）。確認ダイアログの「消す」は履歴に積む前のゲートであり、積んだあとも取り消せる。

確認ダイアログに出す情報（実行前）:

- 対象の表示名（重複時は親名と種別を添える。C10 の「???州」10 件対策）
- 見る年における形の有無
- 参照している地物の件数と名前（最大 10 件 + 「ほか n 件」）
- 最後の外周を消す場合は「面ごと消えます」（N-05）
- 錨を消す場合は「この年の記録が無くなり、直前の記録が続きます」

現行の一括掃除を所有者が選んだ場合のフォールバック: 掃除する参照の一覧を同じ確認に出し、黙って消さない。どちらでも「確認なし即実行」（N-05 の錨削除・リング削除・頂点削除）は廃止する。地物削除の確認（FR-85）は既にあるので、同じ器に揃える。

見るモードでの「地物を削除」だけが生きている欠陥（N-03、`PropertyPanel.tsx:440-447`）は、K-6 の一括無効に乗せて塞ぐ。これは裁定不要の欠陥修正。

## B. 画面構成

大枠（左＝道具、中央＝地図、右＝情報、下＝時間）は定石どおり残す（01 §9.3「作り直しても骨格は変えなくてよい」、FR-111）。変えるのは (1) 上部が窓幅で折り返して地図が動くこと、(2) 時間帯 201px が空なこと、(3) 右が排他タブなこと、(4) 状態がどこにも無いこと、(5) 確定ボタンが地図を隠すこと。

### B-1. 寸法の約束（両窓共通）

行の高さは**選択にも道具にも依存させない**（K-3）。窓幅で折り返さない。溢れた部品は「ほか」メニューへ送る。CSS は `flex-wrap: nowrap` と固定行高。現状の `.app-shell__topbar { flex-wrap: wrap }`（01 §1.3、`shell.css:165-179`）は廃止する。

| 行 | 高さ | 中身 | 伸縮条件 |
| --- | ---: | --- | --- |
| 1. メニュー行 | **32px 固定** | 左: 5 メニュー。中央: 開いているファイル名と未保存印。右: 中心経度（数値＋ジョグ＋直接入力）と階層の深さ（数値＋±）。幅は選択に依存しない固定スロット | 無し |
| 2. 作業バー | **36px 固定** | 左: いまの道具。中央: 次の一手（常時日本語）。右: 確定／やめるの固定スロット（空のときも幅を取る。無効は灰色＋理由） | 無し（文言だけ差し替え） |
| 3. 主行 | **残り全部** | 左レール 148px ＋ 地図 1fr ＋ 右 300px | 窓サイズのみ |
| 4. 時間帯 | **80px 固定** | 現在年、軸（密度＋選択中の節目の印）、±1／±10／±100、年入力（Enter 確定）、再生 | 無し。エラーは作業バーへ出し、帯を伸ばさない（現状はエラー 1 行で 200→220px、01 §1.3） |
| 5. 状態行 | **28px 固定** | カーソル座標、縮尺、直前の結果（消えない）、取り消し可否 | 無し |

縦のクローム合計 = 32+36+80+28 = **176px**（現状 1280 で 310.4px、1600 で 283.2px。01 §1.2）。測量を ON にしても行は増えない（N-54 の 87〜95px 縮みを構造的に消す。測量は道具であり、読み取りは作業バーと状態行へ出す）。

横の固定クローム = 148+300 = **448px**（現状 340px）。縦を削った分で地図面積は増える（下記）。

個別フォーカス 4 部品（起動直後から灰色で 400px 弱、01 §1.3、U-25/U-26 とは別の E-3）はメニュー行に置かない。地物を選んだときだけ、右のプロパティと一覧の行内に出す。**上部の幅が選択で変わらない**（部品自体が上部に無い）。K-3 の守り方を変える（E-3。不変条件そのものは維持）。

中心経度はメニュー行右の固定スロットに残す（U-25 の「数値を常に見せる・直接入力できる」、U-26 の「地図に重ねない」）。ジョグ・数値・入力の 3 つを 1 スロット 240px に圧縮する。階層の深さは同スロット 120px（「深さ 0 / 1」＋±）。グリッドは表示メニュー。測量は左レールの道具。

### B-4. 800×600（FR-114 could）と折り返し禁止の説明

現状は 1 行目最小幅 820.6px で右端 20.6px が到達不能、編集ツール 8 個中 5 個が窓外（01 §1.2）。本案は:

- メニュー行 nowrap。右スロット 360px を優先し、ファイル名を 80px まで省略。5 メニューは文字のみ 180px。
- 左レールは 120px に縮め、ラベルは 2 行にせず省略＋ツールチップ（ツールのツールチップは U-9 の対象外。モードボタンにだけ付けない）。

## D. 状態機械

### D-1. 軸

```
錠:     見る  ⇄  直す
道具:   なし | 選ぶ | 点 | 線 | 面 | 頂点 | 動かす | 分ける | 所属 | 合わせる | 穴 | 穴あけ | 測る
選択:   なし | 地物 1 件（FR-79）＋ 頂点集合（FR-80）
下書き: なし | 追加の途中 | 手順の途中（対象選択 → 入力 → 確認）
時刻:   見る年 = 時間帯の現在時刻
        直す年 = 選中の節目の開始。未選択なら見る年
汚さ:   きれい | 未保存
```

見るのとき道具は物理的に残すが全部無効（K-6 一括。個別判定しない）。作業バーは「見る専用です。直すを押すと国境を動かせます。選ぶことはできます。」

### D-2. 遷移と、何が保持され何が捨てられるか

K-5（一時的な UI 状態は全経路で捨てる、開発ガイド §5.2）との整合: **本案は「一時状態」を下書き（描きかけ・手順の途中・モーダル入力）に限定する。選択と見る年は作業の文脈であり、一時状態ではない。** 現行 `setMode` が選択を捨てる契約（`store.ts:1399-1401`）は変える。これは K-5 の再解釈なので、実装時に開発ガイド §5.2 の検出（キャンセル→再作成／確定→再作成）へ「選択は残る、下書きは捨てる」を明記してテストを足す。

| きっかけ | 捨てる | 保持する | 備考 |
| --- | --- | --- | --- |
| 見る → 直す | 下書き（無いはず） | 選択、見る年、直す年、カメラ、絞り込み | 作業バーが次の一手を「選ぶ」に更新 |
| 直す → 見る | 下書き（確認: 「描きかけを捨てますか？」危険なら） | 選択、年、カメラ | 編集経路一括無効。N-03 塞ぎ |
| 道具を持ち替える | 下書き（K-5） | **選択を保持**（現行の既定を逆転。`preserveSelection` を既定 true に。結合点 6） | 「探してから道具」が通る（C5） |
| 追加の確定 | 頂点列の下書き | 新地物を選択に再解決（開発ガイド §5.11） | フォームは中身区画。年代は見る年（G-8） |
| 追加の Escape | 下書き | 以前の選択があれば戻す | U-5: 描きかけのキャンセルが優先 |
| 手順道具の開始 | なし（対象は選択から引き継ぐ） | 選択を対象に昇格 | 右クリック起動と同じ（現行は右クリックだけ引き継ぐ、C9） |
| 手順の確定 | 下書き、対象 | コマンド結果から選択を再解決。Ctrl+Z は直後からドメイン履歴 | 現行は確定直後 Ctrl+Z が無反応（報告 04 §3.5）。本案は `shortcutsSuspended` を「下書き中はグローバル undo を止めて下書き undo に繋ぐ」に限定し、確定と同時に解除 |
| 手順のキャンセル | 下書き | 開始時の選択 | |
| 時間を動かす | 打ちかけの年入力以外の下書きは捨てない。**属性の打ちかけは警告**（N-04） | 選択。その年に存在しなければ選択解除（開発ガイド §5.5）＋状態行に「この年には存在しません」 | 見る年と直す年のずれを状態行と作業バーに出す |
| 節目を選び直す | 属性の打ちかけは「捨てますか？」 | 地物選択 | N-04 の黙消を禁止 |
| 一覧の行 | なし | その地物を選択、視点を合わせる（U-4）。通史なら見る年もその節目へ | タブ切替が無いので往復ゼロ |
| 空クリック / Escape | 頂点集合、地物選択（下書きが無いとき） | 年、カメラ、道具 | U-5 |
| ファイルを開く / 新規 | すべて（未保存確認のあと） | なし。履歴は作り直し（結合点 9） | タイトルと状態行を更新 |
| 保存成功 | なし | すべて。汚さをきれいへ | 状態行「保存しました 14:23」。タイトルから ● を外す。自動消滅しない |

### D-3. 見る年と直す年（C8-4 の可視化）

```
見る年 ≠ 直す年 のとき
  作業バー: 「地図は 1200 年です。名前の保存は 0 年の記録を変えます。」
  中身区画: [この 1200 年に新しい記録を作る] [0 年の記録を上書きする]
  時間軸: 見る年に再生ヘッド、直す年の印を強調
```

形を変える編集は見る年に節目を打つ（現行どおり、01 C8-4）。属性の保存は利用者が選ぶ。既定は「新しい記録を作る」（エラー防止。過去を黙って消さない）。これが C2(a) の入口（全ソースに 0 件だった「錨を追加」）。

### D-4. キーボード占有（結合点 5）

現行は 11 項目の手書き OR（`App.tsx:2755-2792`）。本案は 3 段:

1. モーダル（設定・重なり・確認・修復・未保存・初回ガイド）→ グローバル打鍵は全部止まる。Esc はモーダルを閉じる。
2. 下書き（追加の途中・手順の途中）→ Ctrl+Z は下書きの一手戻し、Esc はやめる、Enter は確定（可能なとき）。ドメインの取り消しは止める。
3. それ以外 → ドメインの取り消しが生きる。スライダーにフォーカスがあっても Ctrl+Z はドメインへ（現状の暴発対象を `focus-guard.ts` で range も守る側に直す。01 C8）。

新しいモーダルを足すときは段 1 の集合に 1 行足す。OR の手書きをやめる。

### H-3. 初回ガイド（FR-118）の 4 枚

- いま: 「地物がありません。地図に地物を追加すると一覧に表示されます。」（`strings.ts:101`）

### I-5. 右クリック

メニューバーはマウス専用のままにしない（N-42）。Alt は使わない（Electron との衝突回避）。左 Alt でメニューフォーカスは自前実装するなら増分外。本案は F10 で先頭メニュー。実装コストが高いので増分 7 以降。必須は道具の単一キーと時間の [ ]。

ショートカット一覧（ヘルプ）は「拡大が 4 行」を 1 行に畳み、下書き中の Ctrl+Z / Esc / Enter / Shift を載せる（N-35）。学習教材としてグループ（ファイル／取り消し／地図／時間／道具）。
