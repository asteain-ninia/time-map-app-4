### (2) 守り A・B の既定と、「そのまま残す」のやり直し — 記録は消えない

- **どの行でも先頭が記録を消す方法になっていない**: `repairOptionsFor` の全組み合わせ（`repair-option-order.test.ts`）で、2 つ以上の行は先頭が Drop でない、1 つだけの行は名指しの 4 種類（＋子を持つ末端以外の形状保持違反）を除いて Drop でない。重なりの 2 種類は［そのまま残す, 一方を除外］。
- **名指しで外した 5 種類の理由**: 頂点の参照切れ（形が解けない）・輪の階層の不整合（面積・包含が成り立たない）・歴史の重複（年ごとの姿が決まらない）・形の無い末端（描けない）は、残したまま開くと画面や計算が壊れる理由で妥当。**集約と和の不一致（`aggregate-sum-mismatch`、下位領域の間の隙間）だけは「既存の振る舞い」が理由で、形が壊れる理由ではない**。隙間は見た目の隙間であって、残しても計算は成り立つ見込み（確かめていない）。捨てるのはまとめ役の名前・属性で、「削除以外で消えるのは良くない」に照らすと残す選択肢を足す余地がある。この範囲の外の既存の形なので重さ 1。
- **「そのまま残す」→ 保存 → 開き直し → 同じ行 → 選び直し**:
    - K1（守り B が掛かる形 D）: 既定で開く → 同じもの → 保存前の検査は空 → 直列化して読み直すと **同じ行が同じ既定・同じ理由で出る** → 「直轄領を生成」を選ぶと解け、1300 年の親は 10,000 のまま。
    - K1b（守り B が掛からない形 B）: 「そのまま残す」を選んで開く → 同じもの → 読み直すと同じ行（既定は「直轄領を生成」のまま）→ 既定で解ける。
    - K2（重なり A・B）: 既定「そのまま残す」で開く → 同じもの・消えた地物 0 → 保存前の検査は空 → 読み直すと同じ 2 行 → 「一方を除外」を選び直すと適用される（A が消え B が残る。選んだとおり）。
    - E2E の 3 本目が実アプリの保存の経路で同じこと（既定で開く → 状態行「そのまま残した」→ 開き直して「直轄領を生成」→ 1 枚で解け、1300 年の面積が 1050 年と同じ）を通している。
- `sameKeptIssue` は重なりを組（id の集合）で見るので、2 枚目の板で前の回に残した重なりの行を聞き直さない。`keptFeatureCount` は同じ組の 2 種類（末端の重なり・同時刻の重なり）を 1 つに数える（K2 で kept=2 行 → 1 件）。
- 板と適用は同じ project で行を作る（`promptRepair` に渡す project と `buildRepairRows` の context は、1 枚目は読み込んだもの、2 枚目は `applied.project` で一致）。

### (3) 幾何の変更が、子が居続ける普通の形を変えていないこと

- **親の錨が 1 本の形（A 同じ年に子 3 人・B 違う年の子・C 1050/1100/1200 の子 3 人・G さかのぼり・J 子の系列が 2 本）**: 既定は「直轄領を生成」のまま（理由の行なし）で、1 枚で解け、どの年も親の見える面積は同じ、重なり 0、保存 → 読み直しの検査は空。**前回（r3）と同じ結果**。
- **親の錨が 2 本以上で子が居続ける形（E・E2・F3・H）**: 「直轄領を生成」の結果は前回と同じ（1 枚で解け、面積は変わらない）。**ただし既定が変わった**（下の重さ 2）。
