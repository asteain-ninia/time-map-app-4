
- 重さ: 画面の入力は格子（1e-7 度）に丸められ、ナイフには頂点への吸着が無いので、**実際に起きることはほぼ無い**。

- 直し方の案: 代表点を「切片の頂点」ではなく **隣り合う 2 点の中点**（境界から離れた区間の中点）から取る。あわせて、切片の途中の点が環の上にあるときはそこで切片を区切る。
