## (2) 正しさの反証

### 所属変更の各枝と錨

差分から確実に言える範囲は次です。

- 既存の親を選ぶ枝では `gainingParentId` がその親を返します。親が末端なら直轄領の予告対象、集約なら直轄領なしです。

- 最上位へは `None` なので直轄領予告はありません。
- 名前は `directDomainNameOverride` から `buildDirectDomainForLeaf` まで届き、空文字なら既定名へ戻ります。

### 複数対象の洗い直し

`planAffiliationTargets` の挙動は以下です。

- その年に存在しないID: `missing` として外す。
- 集約: `resolveTargetLeaves` で展開。空の集約は `empty-aggregate` で外す。
- 重複した末端: `seen` で重複排除。
- 集約とその子が同時に対象: 子の最終集合は重複排除される。
- 重複した不在ID／空集約: `dropped` 側では重複排除されない。
- 自分自身が親: この関数は親決定を受け取らないため扱えない。候補選択または提案生成で拒否されるかは未確認。
