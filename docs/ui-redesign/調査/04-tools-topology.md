## 1. まとめ（再設計に直結する要点）

1. **所属変更に「新しい上位領域を作る」枝が本当に無い**。UI のボタンは 4 つだけで、ドメイン側の `parentCreate` / `parentCreateWithTerminal` を UI が import すらしていない（§4.3、現状.md R2・R3）。結果として用語集の**連邦化・自治化は実行不能**。
2. **直轄領の名前は一切聞かれない**。所属変更を確定した瞬間、確認も通知もなく「〈元の名前〉 直轄領」という地物が 1 件増える（実測: 775 件 → 776 件、`トランツィ湾の海域09 直轄領`）。ダイアログは出ない（§4.3、現状.md R4）。
3. **5 つのどの操作も「成功した」と言ってくれない**。確定すると画面上の選択が消えて次の対象待ちに戻るだけ。エラーだけは赤帯で出る。
4. **クリックで拾えるのは常に末端地物だけ**（`src/ui/live-lookup.ts:383` の `leafAtPoint`）。画面には階層深度 0 で丸めた集約が描かれているのに、クリックはその下の末端を拾う。「見えているものと掴めるものが違う」。副作用として、**集約地物をまとめて所属変更する経路が UI に無い**（FR-48 の「集約地物は全下位領域を対象に行う」が到達不能）。
5. **ツールを選んでいる間は Ctrl+Z も右クリックメニューも効かない**（`src/ui/App.tsx:2780-2791`）。確定後もツールは次の対象待ちで居座るので、**やり直すにはいったんキャンセルしてツールを降りる必要がある**（実測、§3.5）。
6. **選んだ対象の名前がどこにも出ない**。所属変更でも結合でも、選択中の地物名・件数は画面に文字として出ず、地図上の淡い塗りだけが手掛かり（`reparent-target` などの ID 表示は `hidden` 属性つきでテスト専用）。
7. **結合ダイアログの「既存の上位領域から選ぶ」は 773 件の素のプルダウン**（実測）。絞り込みも検索も無い。
8. 5 つのツールの**確定後のふるまいがバラバラ**（分割だけツールが外れ、他は次の対象待ちで残る、§3.4）。
9. 新規地物の入力フォームは**名前しか聞かない**うえ、見出しが二重に出て、取消ボタンが「追加をキャンセル」（分割・穴あけの文脈に合っていない）（§3.3）。

## 3. 5 つのツールに共通する骨格

### 3.1 入口は 2 つ、ただし片方は半分死んでいる

| 入口 | 分割 | 所属変更 | 結合 | 穴あけ | 測量 |
| --- | --- | --- | --- | --- | --- |
| 左ツールバー（編集モード） | ○ | ○ | ○ | ○ | — |
| 上部バーのトグル | — | — | — | — | ○ |
| 地物を右クリック | ○ | ○ | **常に灰色（無効）** | 無し | 無し |

- 右クリックメニュー（末端地物）の実測: `削除 / プロパティ編集 / 分割 / 所属変更 / 結合（無効） / この地物を非表示 / この地物を強調 / 表示専用モード切替`（`shots/04-ctx-01-右クリックメニュー.png`）。
- **「結合」は必ず無効**。理由は「1 件しか対象が無いから」で固定されている（`src/domain/context-menu/compose.ts:266-268`。無効理由の文言は `src/domain/context-menu/items.ts:110`「結合には2つ以上の対象が必要です。結合する相手を追加してください。」）。押せるようになる状況が存在しないので、実質「出るだけの項目」。
- **集約地物を右クリックしても分割・所属変更・結合は出ない**（`src/domain/context-menu/compose.ts:344-349`）。
- **右クリックから起動しても対象は引き継がれない**。実測: 地物 `area-032` を選んで右クリック →「所属変更」→ ツールは起動するが `reparent-target` は空で、ガイドは「所属を変更する地物をクリックで選択してください。」（`shots/04-ctx-02-右クリックから所属変更.png`）。**同じ地物をもう一度クリックし直す必要がある**。

### 3.2 画面の作り（4 ツール共通）

地図の上に、透明な入力レイヤと以下の 3 つが浮く（`src/ui/knife/knife.css` / `merge.css` / `reparent.css` / `drill.css` はどれも同型）。

| 部品 | 位置 | 内容 |
| --- | --- | --- |
| ガイド帯 | 地図の上端中央、黒い半透明の帯 | 現在の段階の指示文（FR-92） |
| 赤い帯 | ガイド帯の下 | 拒否メッセージ。次の意味のある操作まで残る |
| ボタン列 | 地図の下端中央、白い箱 | 確定 / 取り消し / 選択クリア / キャンセル |

- ボタン列は**幅が中身なりで、日本語が折り返す**。所属変更では 4 つとも 2 行に折り返している（`shots/04-reparent-03-新上位領域選択後.png`）。
- 選択中の対象は**地図上の淡い色分けだけ**。所属変更は対象＝橙、新しい上位領域＝桃色（`src/render/reaffiliation-batch.ts` の `buildReparentHighlight`）。実データの海域のような細い地物では点にしか見えない。
- **件数も名前も文字で出ない**。結合の選択件数は `data-testid="merge-target-count"` に入っているが `hidden` 属性つき（`src/ui/merge/MergeToolController.tsx:344-346`）。所属変更の対象・親も同様（`src/ui/reparent/ReparentToolController.tsx:352-357`）。

### 3.3 新規地物のプロパティ入力（分割・穴あけで共用）

追加モードの `AddPropertyForm` をそのまま再利用している（`src/ui/knife/KnifeToolController.tsx:679-694`、`src/ui/drill/DrillToolController.tsx:462-490`）。実測した見た目（`shots/04-knife-06-非継承側プロパティ.png`、`shots/04-drill-04-新地物プロパティ.png`）:

```
新規地物のプロパティ      ← ツール側の見出し (h3)
新規地物のプロパティ      ← フォーム自身の見出し (h2)
名前 [            ]
[保存] [追加をキャンセル]
```

- **見出しが二重**（`KNIFE_STRINGS.newFeatureProps` / `DRILL_STRINGS.newFeatureProps` と `ADD_STRINGS.formTitle` が同じ文字列）。
- **取消ボタンが「追加をキャンセル」**（`src/ui/add/strings.ts:23`）。分割・穴あけの文脈では「追加」ではない。しかもこれを押すと**操作全体が取り消される**（切った形も戻る）。
- 聞かれるのは**名前だけ**。開始年・終了年・色・種別ラベルは入力できない（現状.md R5・R10）。親領域の欄はツール側が隠している（親は元の地物から自動継承するので、これは意図的）。
- この入力箱には**背後を塞ぐ幕が無い**（`src/ui/knife/knife.css:157-170`、`src/ui/drill/drill.css:66-77`）。継承先ダイアログと結合ダイアログには幕がある。つまり分割・穴あけの最終段階だけ、背後の地図が操作可能なまま。

### 3.4 確定した後のふるまいがツールごとに違う（実測）

| ツール | 確定後の状態 | ツールバーのボタン |
| --- | --- | --- |
| 分割（ナイフ） | ツールごと解除。パネルが消える | 押下状態が解除される |
| 穴あけ | 「対象選択」に戻って居座る | 押下状態のまま |
| 結合 | 「対象選択」に戻って居座る | 押下状態のまま |
| 所属変更 | 「対象選択」に戻って居座る | 押下状態のまま |

分割だけ 1 回で終わる。連続で同じ操作をしたい人には穴あけ／結合／所属変更の方が親切だが、統一されていない。

### 3.5 ツールを選んでいる間は Ctrl+Z も右クリックも止まる（実測）

`src/ui/App.tsx:2780-2791` の `shortcutsSuspended` は、5 つのツールのどれかが**アイドルでない**間ずっと真になる。ツールは起動した瞬間から「対象選択」＝アイドルでないので、**ツールを選んだだけで全体ショートカットが止まる**。

実測（所属変更）:

| 操作 | 結果 |
| --- | --- |
| 所属変更を確定 → 地物 775 → 776 件（直轄領が増える） | 成功。メッセージ無し |
| そのまま Ctrl+Z | **何も起きない**（776 件のまま） |
| 「キャンセル」でツールを降りてから Ctrl+Z | 775 件に戻り、直轄領も消える |

同じく、ツールが起動している間は**右クリックしてもメニューが出ない**（`src/ui/App.tsx:1352` の `suspended` が同じ値を読む。実測で確認、`shots/04-common-02-ツール中は右クリックメニューが出ない.png`）。

### 3.6 対象の拾い方（5 ツール共通の落とし穴）

分割・結合・所属変更・穴あけ・穴飛び地はすべて `leafAtPoint`（`src/ui/live-lookup.ts:383-414`）で末端地物だけを拾う（`src/ui/App.tsx:4139, 4229, 4318`）。ここから次が導かれる。

- 画面が階層深度 0（集約に丸めた表示）でも、クリックは丸める前の末端を拾う。**見えている国をクリックしたのに、その中の州が選ばれる**。
- 集約地物は**絶対に対象にできない**。したがって:
  - 「集約地物には穴あけできません。末端地物を選んでください。」（`src/ui/drill/strings.ts:27`）と「集約地物は分割できません。末端地物を選んでください。」（`src/domain/knife/split-geometry.ts:82`）は**地図クリックでは到達しない死んだ文言**。
  - 所属変更の拒否文言のうち「対象自身を〜」「対象の下位領域を〜（循環参照）」「点情報・線情報は〜」（`src/domain/affiliation/messages.ts:10-31`）も、末端しか拾えないため到達しない。
  - 結合の「互いに上位・下位の関係にある面情報は結合できません。」も同様に出しにくい。
- つまり**ガードレールの文言はほぼ空振り**で、実際には拒否されずに通ってしまう操作ばかり。
